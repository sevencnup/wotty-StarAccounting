# Web 简体中文与英文双语功能开发文档

## 目标

为 Web 应用增加可用的简体中文与英文界面。用户可以在账户页切换语言，选择结果即时生效、跨页面保持，并在刷新后恢复。

## 实施步骤

 - [x] 扩展语言设置模型，明确简体中文与英文 locale。
 - [x] 增加全局语言状态、持久化和页面初始化逻辑。
 - [x] 为主要页面、导航、面板、按钮、提示和表单补充英文翻译。
 - [x] 让动态消息和常用属性（placeholder、aria-label、title）跟随语言切换。
 - [x] 验证语言切换、刷新恢复、跨页面保持和窄屏布局。
 - [x] 运行测试、类型检查和生产构建。
 - [x] 更新版本记录并完成本地 Git 提交。

## 验收标准

1. 账户页语言设置提供“简体中文”和“English”。
2. 选择 English 后，主要页面界面显示英文，HTML `lang` 为 `en-US`。
3. 选择简体中文后恢复中文界面，HTML `lang` 为 `zh-CN`。
4. 语言设置刷新后仍然保留，并在导航到其他页面时继续生效。
5. 主要弹窗、表单按钮、导航和错误/空状态文案不会混用语言。
6. 窄屏下切换语言不产生横向溢出。
