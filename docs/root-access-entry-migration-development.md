# 根路径统一访问入口迁移开发文档

## 目标

- 将当前移动端账本路由从根路径迁移至 `/app`，根路径 `/` 专职承载 API 检测、登录注册和模式选择。
- 为未来 `/web` 桌面端预留同一套入口认证和受保护路由机制。
- Android Capacitor App 仍可在根入口选择本地模式并进入 `/app`；浏览器仅允许云端模式。
- 用户直接访问 `/app/*` 时，必须先完成数据模式与云端登录校验，未通过则回到根入口。

## 实施步骤

1. 将现有 `(tabs)` 路由组移动到 `/app/(tabs)`，使移动端页面统一以 `/app` 为前缀。
2. 将入口组件改为根路径专用流程：校验 API、登录注册、选择本地/云端，并在成功后跳转到安全的目标路径。
3. 增加可复用的受保护路由组件，供 `/app` 以及未来 `/web` 布局在直接访问时验证会话和数据模式。
4. 调整设置页的模式入口，使其跳转到根路径统一入口而非在业务页面中弹层。
5. 更新版本记录，执行类型检查、测试、生产构建、差异检查并提交本地 Git。

## 验收标准

- 访问 `/` 只能看到统一入口，不会挂载账本业务页面。
- 现有移动端页面可通过 `/app`、`/app/accounts` 等路径正常访问。
- Web 浏览器不能启用本地模式；Capacitor App 可以选择本地模式进入 `/app`。
- 无有效云端会话直接访问 `/app/*` 会回到 `/?next=...`；登录完成后回到目标页。
- 未来 `/web` 可复用受保护路由组件与根路径登录入口。
