# 云端密码重置开发文档

## 目标

- 在“设置 → 切换模式 → 云端模式”区域增加“重置密码”入口。
- 已登录云端账户可以输入当前密码、新密码和确认密码完成密码修改。
- 后端必须校验当前密码，并使用现有 PBKDF2 逻辑保存新密码。
- 未登录请求不能修改密码；修改成功后当前 JWT 继续有效。

## 实施步骤

1. 在 API 增加受 JWT 保护的密码修改接口，校验当前密码、新密码长度和确认值。
2. 在 Web 增加接口调用封装和云端模式下的重置密码表单。
3. 增加 API/Web 相关测试或执行现有类型检查与测试，确认不影响登录和云端模式切换。
4. 更新版本记录，仅记录本次功能更新描述。

## 验收标准

- 云端模式区域可看到“重置密码”入口。
- 未登录不能提交密码修改。
- 当前密码错误时修改失败，新密码不会写入。
- 新密码少于 8 位或两次输入不一致时，前后端均能给出错误提示。
- 当前密码正确时修改成功，之后可使用新密码登录。
