# 账单导入可靠性修复开发文档

## 目标

让本地与云端模式都能够可靠导入微信、支付宝账单，并改为选择文件后预览、用户确认后再写入数据。

## 范围

- 自动根据账单内容识别微信或支付宝，不因界面初始选择不同而阻止导入。
- 选择文件后显示文件名、识别的平台与有效流水数量；仅在用户点击确认后导入。
- 本地模式复用相同的订单号去重策略；云端模式调用后端批量导入接口。
- 在界面中显示明确的解析或导入错误，避免只显示笼统失败信息。

## 实施步骤

- [x] 梳理文件选择、解析、本地仓库及云端仓库的完整调用链。
- [x] 为云端批量导入接口与本地批次去重补充回归测试。
- [x] 修复云端仓库未使用批量导入接口的问题。
- [x] 将文件选择改为解析预览与手动确认，自动采用识别的平台。
- [x] 补充可读失败提示，并运行测试、类型检查和生产构建。
- [x] 打包 APK、Wi-Fi 覆盖安装并完成本地 Git 提交。

## 验收标准

1. 微信和支付宝 CSV/XLS/XLSX 文件可在本地、云端模式下完成导入。
2. 选择错误的平台不会导致有效账单被静默拒绝，界面会采用自动识别的结果。
3. 在点击“确认导入”前不写入任何流水。
4. 同一订单号不会因同一批文件中的重复行而重复写入。
5. 云端模式只用一次批量请求提交该文件的流水。
