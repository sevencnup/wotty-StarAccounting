# Web 首页移除流水并替换为消费结构与财务行动建议开发文档

## 1. 需求与优化目标
首页定位为**“财务大盘驾驶舱 (Executive Dashboard)”**，而非操作层的明细清单：
1. **移除冗余的「最近记账流水」**：二级 Tab 已有专属流水明细页，首页平铺流水显得琐碎且割裂。
2. **新增「本月主力支出分类构成 (Top Expense Structure)」**：
   - 彩色分段比例条直观反映钱花在哪。
   - 2×2 排列主力消费分类金额与占比，点击可直达对应分类明细。
3. **新增「智能财务行动建议 (Smart Financial Advice)」**：
   - 基于当月日均消耗、结余预测与储蓄进度给出明确的理财指引。
