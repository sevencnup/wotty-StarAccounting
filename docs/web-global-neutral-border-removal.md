# 全局中性灰边框移除

## 目标

移除 Web 端通用卡片、表单控件、普通按钮、列表分隔和数据表格中的中性灰色描边，使页面通过留白、浅色底和阴影区分层级。

## 保留范围

- 红色错误、黄色提醒、绿色成功、蓝色焦点及主操作的语义状态边界。
- 图表、进度环和插画中非界面描边。
- 必须依赖颜色表达状态的边框。

## 实施步骤

- [x] 识别全局边框变量、通用控件与直接声明的中性灰边框。
- [x] 增加统一的无中性描边视觉覆盖，保留语义状态边界。
- [x] 在首页、储蓄编辑、资产与设置页面检查视觉层级。
- [x] 运行生产构建并完成本地提交。

## 验收标准

1. 普通卡片、输入框、下拉框、非主操作按钮和列表没有可见灰色条线。
2. 聚焦输入框仍有清晰可见的蓝色提示。
3. 错误、成功、提醒等语义状态没有被误清除。
4. 表格内容仍可通过底色和间距辨认。
