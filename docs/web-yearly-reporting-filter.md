# 年度筛选开发文档

## 问题

当前月份选择弹窗虽然可以切换年份，但只有点击具体月份后才能返回筛选值，无法直接按整年查看数据。

## 目标

为首页和消费页面增加“全年”筛选：用户切换到目标年份后可以直接选择全年，页面按该年份 1～12 月加载和统计；具体月份筛选继续保留。

## 设计

- 月份值继续使用 `YYYY-MM`。
- 年度值使用 `YYYY`，公共格式化和日期范围函数识别年度值。
- 月份选择弹窗在年份控制下增加“全年”按钮。
- 首页年度视图加载该年交易，趋势按 12 个月展示。
- 消费页年度视图加载该年交易，消费节律与每日平台图表按年度视图展示月度汇总；商家、分类和账户统计使用全年数据。

## 验收标准

1. 选择年份后点击“全年”，无需再点月份即可完成筛选。
2. 首页和消费页显示“YYYY年全年”，数据只包含该年份。
3. 选择具体月份后，现有月度筛选行为不变。
4. 年度和月度切换不会残留上一次筛选条件或加载错误。
5. 手机、App 和桌面端均可操作。
