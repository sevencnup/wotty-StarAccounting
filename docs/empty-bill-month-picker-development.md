# 无账单月份禁用开发文档

## 目标

- 首页和消费分析页的月份选择器只允许选择当前账本中存在流水的月份。
- 没有账单的月份显示为灰色并禁用点击。
- 保留全年统计入口，并在没有全年流水时同步禁用。

## 实施步骤

1. 让月份选择器接收当前账本的有流水月份集合，并为无流水月份设置禁用状态。
2. 首页和消费分析页加载全部账本流水，仅提取月份作为可选状态，不改变原有统计口径。
3. 增加灰色禁用样式和无障碍属性，执行类型检查、测试和生产构建。
4. 更新版本记录，并完成本地 Git 提交，不推送 GitHub。

## 验收标准

- 有流水的月份可以正常点击切换。
- 无流水的月份为灰色且点击无效。
- 首页、消费分析页行为一致。
- 年度统计仍可选择；无全年流水时全年按钮不可点击。
