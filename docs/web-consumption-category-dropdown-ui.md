# 消费页分类下拉菜单 UI 优化开发文档

## 目标

优化消费分析页筛选栏中的“分类”菜单，解决原生下拉菜单在移动端样式不可控、选中态突兀、信息密度低的问题。

## 实施步骤

- [x] 将分类原生 select 替换为页面内自定义下拉菜单。
- [x] 为分类项增加图标、流水数量和清晰的选中态。
- [x] 支持点击选择、点击外部关闭和 Esc 关闭。
- [x] 保持现有分类筛选逻辑与账户下拉菜单不变。
- [x] 完成类型检查、构建和差异检查。
- [x] 更新版本记录并完成本地 Git 提交。

## 验收标准

1. 分类菜单在手机宽度下以圆角浮层展示，不再使用浏览器默认灰色选中项。
2. 当前分类有明显高亮和勾选标记，分类项显示对应图标与流水数量。
3. 菜单不会造成页面横向溢出，长分类名称能够省略显示。
4. 选择分类后，消费图表和流水明细仍按原有逻辑筛选。
5. pnpm typecheck 与 pnpm build 通过。
