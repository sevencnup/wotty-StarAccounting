# 主标签页返回策略开发文档

## 目标

- 底部主标签页（首页、消费、储蓄、贷款、资产、设置）之间切换时，不再逐个写入浏览器历史记录。
- Android WebView 的边缘侧滑与浏览器返回仍优先交给已打开的分层弹层；没有弹层时，不再在主标签页之间来回切换。
- 保留独立路由页面、详情页和表单的正常返回语义，以及长时间后台恢复后的导航自愈逻辑。

## 实施步骤

1. 将底部主导航的正常客户端跳转改为替换当前历史记录，而不是默认追加记录。
2. 保持后台恢复后的硬重载分支，确保失活的 Android WebView 仍直接重建用户选中的标签页。
3. 调整导航规划单元测试，明确普通标签切换采用替换策略。
4. 更新未发布版本记录，执行类型检查、测试和生产构建，并提交本地 Git 仓库。

## 验收标准

- 从首页依次点击消费、储蓄、资产后，侧滑返回不会依次回到储蓄和消费。
- 打开日期选择器、表单、筛选或其他弹层时，侧滑仍只关闭最上层 UI。
- `/app/journal`、`/app/budgets` 等独立路由仍可按既有路由历史返回。
- 应用从后台长时间恢复后，第一次点击底部标签仍能正常进入目标页面。
