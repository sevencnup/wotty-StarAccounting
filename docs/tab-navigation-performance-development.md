# 底部标签页切换性能优化开发文档

## 目标

- 缩短底部导航首次切换页面时的代码加载等待。
- 点击非当前标签后立即给出页面切换反馈，不再停留在旧页面等待。
- 保持现有路由、返回行为、记账入口及各页面数据加载逻辑不变。

## 实施步骤

1. 将仅在弹层打开时使用的 `JournalPanel` 从标签布局及各页面首屏代码中拆出，改为动态加载。
2. 底部导航挂载后主动预取其他标签路由，并在指针按下时再次确保目标路由已预取。
3. 接通现有标签页切换骨架屏；点击非当前标签后立即显示，并在路由完成或超时后恢复。
4. 增加标签路由级 `loading` 边界，覆盖浏览器返回、页面内链接等非底部按钮触发的冷切换。
5. 更新版本记录，并执行类型检查、测试和生产构建。

## 验收标准

- 点击当前标签不会重复导航。
- 点击其他底部标签后，导航选中状态和骨架反馈立即更新。
- 标签页路由在空闲阶段被主动预取。
- `JournalPanel` 不再进入各标签页首屏静态依赖。
- 页面切换完成后正常显示数据，记账、储蓄、贷款和资产编辑弹层仍可打开。
