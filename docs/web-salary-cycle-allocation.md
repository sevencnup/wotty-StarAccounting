# 薪资周期与资金去向开发文档

## 目标

按用户设置的发薪日计算薪资周期，并让首页结余统计根据实际发生日期归属消费、储蓄和贷款还款。日历月统计继续保留，用于月度报表。

## 实施步骤

- [x] 增加可复用的薪资周期日期工具，处理月份边界和无效日期。
- [x] 为储蓄计划保存实际存入日期，旧数据兼容为计划更新日期。
- [x] 为贷款还款流水支持实际还款日期与贷款关联，并提供周期统计工具。
- [x] 更新首页薪资周期结余，扣除周期内实际储蓄和实际还款，保留消费按实际日期统计。
- [x] 更新贷款和储蓄页面的周期提示，避免把计划金额当作已发生现金流。
- [x] 统一首页自然月和发薪周期结余公式，并显示两种口径下的四项现金流明细。
- [x] 增加跨月、发薪日、储蓄日和还款日回归测试。
- [x] 更新版本记录，运行测试、类型检查和生产构建。

## 规则

- 发薪日为每月 15 日时，本期为当月 15 日至次月 14 日。
- 消费按流水实际日期归属；不按月份平分。
- 储蓄只有记录实际存入后才扣除本期结余；计划金额不扣除现金流。
- 贷款应还日只用于提醒和预测；有实际还款流水时才扣除本期结余。
- 资产不作为支出扣除，资产余额继续独立维护。
