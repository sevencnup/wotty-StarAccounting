# 储蓄目标编辑月份同步开发文档

## 目标

编辑已有储蓄目标时，月份表格应与该目标实际保存的储蓄计划保持一致，不能被遗留的完整年度配置扩展为全年。

## 根因

编辑表单此前优先使用 \`planConfig\` 的月份。部分旧目标保留了完整年度配置，但实际只保存了少数月份的计划，导致编辑表格错误展示 12 个月。

## 实施步骤

- [x] 定位月份配置与已保存储蓄计划的读取流程。
- [x] 新增纯函数：优先使用显式配置，其次使用已保存计划月份，最后回退默认月份。
- [x] 编辑旧目标时，按储蓄计划记录恢复表格月份。
- [x] 添加“仅有 9–12 月计划的旧目标”回归测试。
- [x] 运行测试、类型检查和生产构建。
- [x] 完成本地 Git 提交。
- [x] 调整优先级：编辑已有目标时，以实际保存计划月份覆盖遗留配置月份。
- [x] 添加“完整年度配置但仅有 9–12 月计划”的回归测试。
- [x] 运行测试、类型检查和生产构建。
- [x] 完成本地 Git 提交。

## 验收标准

1. 即使旧目标遗留完整年度配置，只要实际仅有 9–12 月计划，编辑页也仅显示 9–12 月。
2. 没有任何计划记录的目标仍可按已保存配置或默认值显示月份。
3. 新建且尚无计划的目标仍保留默认月份。
