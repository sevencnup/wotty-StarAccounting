# 储蓄目标编辑月份同步开发文档

## 目标

编辑已有储蓄目标时，月份表格应与该目标已保存的储蓄计划保持一致，不能因为旧数据缺少月份配置而自动扩展为全年。

## 根因

编辑表单在读取旧目标时，只从 \`planConfig\` 获取月份；当旧数据未保存月份配置时，会回退到完整年度，未使用实际存在的计划记录。

## 实施步骤

- [x] 定位月份配置与已保存储蓄计划的读取流程。
- [x] 新增纯函数：优先使用显式配置，其次使用已保存计划月份，最后回退默认月份。
- [x] 编辑旧目标时，按储蓄计划记录恢复表格月份。
- [x] 添加“仅有 9–12 月计划的旧目标”回归测试。
- [x] 运行测试、类型检查和生产构建。
- [x] 完成本地 Git 提交。

## 验收标准

1. 旧目标仅有 9–12 月计划时，编辑页仅显示 9–12 月。
2. 已显式保存月份配置的目标仍按该配置显示。
3. 新建且尚无计划的目标仍保留默认月份。
