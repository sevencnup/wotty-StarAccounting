# 储蓄目标编辑月份同步开发文档

## 目标

编辑已有储蓄目标时，月份表格应展示有内容的历史计划及当前、未来计划，不能因保存过的空白历史行或遗留配置扩展为全年。

## 根因

储蓄规划器会为全年保存空白计划行；编辑表单将这些空白历史行与有内容的计划同等处理，因而显示 1–12 月。截图中的 1–8 月是空行，9–12 月为当前及未来计划，应只显示 9–12 月。

## 验收标准

1. 即使旧目标遗留完整年度配置，只要实际仅有 9–12 月计划，编辑页也仅显示 9–12 月。
2. 没有任何计划记录的目标仍可按已保存配置或默认值显示月份。
3. 新建且尚无计划的目标仍保留默认月份。
4. 2026 年 9 月编辑全年计划时，1–8 月为空、9–12 月为当前及未来月份，应只显示 9–12 月。
