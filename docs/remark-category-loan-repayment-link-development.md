# 归类账单关联贷款还款开发文档

## 目标

- 用户可将账单自定义归类为“招商银行房贷还款”等名称，无须账单原始内容包含银行信息。
- 归类名称同时命中“还款语义”和贷款名称/匹配关键词时，自动将账单绑定为该贷款还款。
- 对已归类的历史账单和后续由关键词规则归类的新账单，均可安全更新贷款待还金额与期数。
- 已关联的账单不能被重复冲销；本地与云端均保证“更新账单与贷款”在同一事务完成。

## 实施步骤

1. 扩展贷款匹配文本，纳入账单的自定义归类；明确归类为还款时允许原始转账类型参与匹配。
2. 增加仓储批量关联操作，只对当前尚未绑定贷款的账单写入还款类型和 `loanId`，并同步更新目标贷款。
3. 在账单归类的单笔保存、关键词规则批量应用完成后，调用批量关联操作；未命中贷款的账单仍按原有消费归类逻辑保存。
4. 云端新增受账户和用户权限保护的批量关联接口，在一个数据库事务内验证、写账单、更新贷款；本地使用一个 IndexedDB 事务完成等价操作。
5. 为“自定义还款名称匹配”“转账账单手动归类”“重复关联不重复扣减”增加测试，并执行前端校验、生产构建和差异检查。

## 验收标准

- 将无银行信息的账单归类为“招商银行房贷还款”后，该账单会成为 `REPAYMENT` 并关联到对应贷款。
- 保存“某关键词 → 招商银行房贷还款”规则时，历史命中账单会批量关联；后续导入命中规则的账单也会自动关联。
- 自定义归类只命中多笔贷款或未包含还款语义时，不会自动关联贷款。
- 已经关联贷款的账单再次保存或规则重复应用时，贷款余额和期数不重复扣减。
