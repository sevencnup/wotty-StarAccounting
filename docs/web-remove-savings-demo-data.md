# 移除储蓄目标演示数据开发记录

## 目标

储蓄页面的目标组只展示用户真实添加的储蓄目标，不自动生成或继续保留演示目标和空的默认占位目标。

## 实施步骤

- [x] 检查本地、云端和 SQL 演示数据中的储蓄目标来源。
- [x] 停止本地和云端生成储蓄演示目标及计划。
- [x] 清理旧版本已写入的固定储蓄演示目标及对应计划。
- [x] 停止打开添加储蓄页面时自动保存空的默认目标。
- [x] 更新演示数据 SQL，避免再次写入储蓄演示目标。
- [x] 运行类型检查、测试和构建。
- [x] 更新版本记录并完成本地 Git 提交。

## 验收标准

1. 新用户打开储蓄页面时不会看到预置储蓄目标。
2. 已知旧版储蓄演示目标不会继续显示。
3. 用户自己添加的目标不受影响。
4. 储蓄计划不会残留指向已清理演示目标的数据。
