# Web 资产页字体与模块统一优化

版本：`0.0.73`

## 目标

在不改变资产页数据、统计口径、交互与 JSX 结构的前提下，统一页面字号层级与模块尺寸，解决“字体大小不统一、模块大一小”的视觉噪声。

## 问题诊断

- 字号散乱：同一层级文字在 8px–13px 之间跳跃（如卡片描述 8px、行内标签 9px、块标题 13px、区段标题 15px、主数字 31px），层级不清。
- 模块尺寸不齐：两侧总览卡片、体检卡片、明细行与表单控件高度/内边距不统一，卡片样式重复且互相覆盖。

## 调整方案

1. 统一字号层级：主数字 31px / 主标题 17px / 区段标题 15px / 块标题与次级金额 13px / 行名与数值 12px / 说明与眉题 11px / 微型辅助文字 10px。
2. 统一模块结构：净资产主卡与三张区段卡共用一致的圆角、内边距和玻璃背景；分隔线间距、明细行高、体检卡、表单控件高度统一。
3. 收敛覆盖声明：卡片外观合并为分组规则，去掉同一资产页内的重复覆盖，避免新旧两套 asset 样式互相干扰。

## 约束

1. 不修改 `web/src/app/(tabs)/assets/page.tsx` 的 JSX 与逻辑。
2. 不改变数据仓库、统计口径与保存流程。
3. 保持 420px / 370px 窄屏无横向滚动与文字溢出。
