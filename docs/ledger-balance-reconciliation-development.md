# 账本余额与资产对账开发文档

## 目标

- 明确区分“本月收支结余”和“当前账本余额”。
- 为账本增加期初余额与期初日期，支持历史导入数据与现有资产对账。
- 对账时用累计流水计算账面余额，不再通过生成本月收入/支出流水掩盖历史差额。
- 本地 IndexedDB 与云端 MySQL 使用同一套字段和计算规则。

## 实施步骤

1. 扩展 Account 模型及 API 账本表，增加可为空的期初余额、期初日期字段，兼容旧数据。
2. 增加纯函数计算累计收入、支出、还款和当前账面余额，并覆盖转账不计入总账余额变化的规则。
3. 重做账户对账面板：显示累计口径，允许保存由实际余额反推的期初余额；不再创建“余额校正”收入/支出流水。
4. 增加单元测试，执行前端类型检查、测试、生产构建和 API 测试。
5. 更新版本记录，仅记录本次功能更新描述。
6. 修改完成后执行本地 Git 提交，不推送 GitHub。

## 验收标准

- 6000 元工资及其他收入、支出会累计到当前账本余额，而不是只拿当月净额与资产余额比较。
- 设置“期初日期”和实际总余额后，系统能计算并保存期初余额，刷新后账面余额保持一致。
- 转账不会被计为收入或支出，也不会改变总账本余额。
- 旧账本没有新增字段时仍能正常启动，默认期初余额为 0、按全部历史流水计算。
- 对账过程不会新增一笔伪造的“余额校正”收入或支出。
