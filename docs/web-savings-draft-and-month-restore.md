# 储蓄计划新增状态与月份恢复

## 目标

- 新增储蓄计划保存后再次打开时，不加载旧目标或已清理的草稿。
- 删除月份后，可以从当前储蓄模式支持的月份中重新添加。

## 实施步骤

- [x] 区分新增储蓄与编辑已有目标的目标选择逻辑。
- [x] 增加月份恢复业务函数和回归测试。
- [x] 在储蓄计划页面增加月份选择和添加入口。
- [x] 验证测试、类型检查与生产构建。
- [x] 更新版本记录并完成本地 Git 提交。

## 验收标准

- 未提供目标 ID 时始终创建全新的储蓄目标，不读取本地第一个旧目标。
- 保存成功后清除当前新增或目标编辑作用域下的草稿。
- 删除月份后可重新添加，月份按自然顺序排列且不会重复。
