# 储蓄目标编辑打开性能修复开发文档

## 问题

在储蓄页点击总目标的“编辑目标”后，编辑页面在手机局域网环境中有约两秒延迟才可使用。

## 定位结果

编辑入口跳转至独立的 `/journal/savings` 路由。该路由首次进入时需要额外下载约 577KB 的页面脚本；储蓄目标和计划接口本身只需几十毫秒。储蓄页已经加载 `JournalPanel` 和 `SavingsPlanner`，因此这次额外路由下载没有必要。

## 目标

点击编辑目标后在储蓄页内直接打开现有的储蓄编辑面板，保持完整编辑能力、关闭后的储蓄页上下文和保存后的数据刷新。

## 实施步骤

- [x] 建立“点击编辑目标至保存按钮可用”的局域网浏览器测量。
- [x] 确认接口耗时很低，独立编辑路由脚本为主要等待来源。
- [x] 将编辑入口改为当前页内打开已有储蓄编辑面板。
- [x] 修正储蓄规划器保存回调，使当前页能刷新已保存的目标和计划。
- [x] 使用真实浏览器验证编辑面板无需路由跳转、打开速度和保存后刷新。
- [x] 运行测试、类型检查和生产构建。
- [x] 更新版本记录并完成本地 Git 提交。

## 验收标准

1. 编辑按钮点击后地址仍为 `/savings/`，不再请求 `/journal/savings` 的页面脚本。
2. 储蓄编辑面板可编辑目标信息和已有计划月份。
3. 保存修改后关闭编辑面板，储蓄页显示最新数据。
4. 既有独立“添加储蓄”路由和关闭行为不回归。
