# 储蓄新增页面客户端异常修复开发文档

## 问题

通过局域网 HTTP 地址打开储蓄页面后，点击“添加储蓄”出现客户端异常页。

## 目标

让储蓄新增面板在 HTTPS、localhost 以及局域网 HTTP 地址下都能正常初始化；同时避免其他新增面板因相同的 UUID API 兼容性问题崩溃。

## 实施步骤

- [x] 确认客户端异常触发点和浏览器 API 兼容性。
- [x] 增加兼容非安全上下文的 ID 生成函数。
- [x] 替换储蓄、记账、资产、贷款和备注规则中的直接 UUID 调用。
- [x] 增加 ID 生成回归测试。
- [x] 运行类型检查、单元测试和生产构建。
- [x] 更新版本记录并完成本地 Git 提交。

## 验收标准

1. 局域网 HTTP 地址打开“添加储蓄”不再出现客户端异常页。
2. 不支持 `crypto.randomUUID()` 的浏览器仍能生成不重复的记录 ID。
3. 类型检查、测试和生产构建通过。
4. 调试进程已关闭。

## 版本记录

### `0.0.1`

### `0.0.2`
