# Web 与 App 入口访问守卫开发文档

## 目标

- Web 浏览器首次进入应用时，必须先验证云端 API 和数据库，再显示登录/注册表单。
- Android 套壳 App 保留本地模式入口；选择本地模式时不依赖服务器，选择云端模式时执行 API 检测和登录。
- 将模式选择和云端登录集中到入口访问页面，设置页只保留进入该页面的入口。
- 云端数据继续由 API JWT 鉴权保护，入口守卫只负责前端访问流程和用户体验。

## 实施步骤

1. 增加可识别浏览器与 Capacitor 原生运行时的模式读取规则，浏览器强制使用云端模式。
2. 在 tabs 根布局增加入口守卫，处理 API 健康检查、已有令牌恢复、登录/注册和本地模式跳过。
3. 将设置里的模式入口改为打开统一入口守卫，不再在设置面板内重复完成模式切换和登录。
4. 增加入口页面样式与错误状态，执行前端类型检查、测试和生产构建。
5. 更新版本记录，并完成本地 Git 提交，不推送 GitHub。

## 验收标准

- Web 未通过 API 健康检查和云端登录时不能看到首页及其他业务页面。
- Web 不能选择本地模式。
- Android App 可以直接进入本地模式，也可以切换到云端并登录。
- 已有有效云端令牌时，刷新页面可以自动恢复；令牌失效时回到登录界面。
- 设置页的模式入口能够重新打开统一入口页面。
- 未登录用户无法通过前端页面拿到云端业务数据，API 仍执行服务端鉴权。
