# 账单关键词归类开发文档

版本：`0.0.84`

## 目标

在账户页的「账单归类」模块中，允许用户输入支付宝或微信流水中的商户、转账对象等关键词，选择消费分类后，一次保存并应用到所有匹配流水，减少在大量账单中逐条查找的操作。现有的单条手动归类继续保留。

## 方案

1. 关键词规则使用现有 `CategoryRule` 数据模型和仓库接口保存。
2. 匹配关键词时忽略大小写，并在流水的商户、描述、平台、支付方式、原始分类和订单号字段中进行包含匹配。
3. 保存规则后，只更新当前账户中匹配的非收入流水，将 `remarkCategory` 设置为目标分类。
4. 规则列表展示已保存规则，支持启用/停用和删除；停用或删除规则不反向清除已经应用的流水归类。
5. 分类沿用现有分类体系；`房租水电`作为可选分类保留，不新增独立统计口径。
6. 规则匹配和批量应用逻辑抽为纯函数并加入回归测试。

## 验收标准

- 输入「房东」、选择「房租水电」并保存后，支付宝/微信中包含「房东」的转账或支出流水显示为「房租水电」。
- 关键词为空时不能保存。
- 规则保存后刷新账户页仍然存在，规则状态可切换。
- 单条流水仍可展开并独立修改或清除归类。
- 类型检查和全部现有测试通过。
