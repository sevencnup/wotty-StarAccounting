# 首页本月预算卡片开发文档

## 目标

在首页增加“本月资金分配”卡片，直接展示收入扣除消费、贷款还款和储蓄后的可支配预算，并提供预算管理入口。

## 计算口径

- 可支配预算 = 当前报表周期收入 - 当前报表周期消费 - 当前报表周期还款 - 当前报表周期实际储蓄。
- 资产页面的余额属于资产存量，不直接从本月收入扣除；卡片单独展示资产存量并标注该口径。
- 支出、还款和储蓄允许使可支配预算为负数，负数表示当前周期已经超出收入。
- 当前报表选择年度时，卡片使用全年数据并显示“全年资金分配”。

## 实施步骤

- [x] 在首页汇总模型中增加资金分配数据。
- [x] 在首页增加本月资金分配卡片，并链接到预算管理页面。
- [x] 移除设置页中的预算管理占位入口。
- [x] 增加中英文文案、样式和关键计算回归测试。
- [x] 运行测试、类型检查和生产构建。
- [x] 更新版本记录并完成本地 Git 提交。

## 验收标准

1. 首页能看到本月资金分配卡片。
2. 卡片主数字等于收入减去消费、还款和实际储蓄。
3. 资产余额会展示，但不会被重复扣除。
4. 点击卡片中的预算管理可以进入已有预算管理页面。
5. 设置页不再显示“预算管理 · 待开发”。
