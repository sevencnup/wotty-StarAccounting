# 页面背景层级调整

版本：`0.0.107`

## 目标

将应用页面底色统一为很浅的冷灰色，同时保留模块和卡片的白色，使内容区与页面背景能够自然区分。

## 实施步骤

1. 将全局背景色变量调整为浅灰色。
2. 让 `body`、标签页外壳和首页固定背景都复用该变量。
3. 保留卡片、表单、弹层等模块现有的白色背景。
4. 运行自动化检查和生产构建，确认页面没有布局或构建回归。

## 验收标准

- 页面内容区的留白显示为浅灰色。
- 白色模块、卡片和输入区域仍然清晰可辨。
- 首页与其他底部导航页面使用一致的背景层级。
- 不出现横向溢出或构建错误。
