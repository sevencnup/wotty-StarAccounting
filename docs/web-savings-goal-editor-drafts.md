# 储蓄总目标编辑草稿开发文档

## 问题

储蓄总目标的编辑页没有保存草稿：关闭页面或中断编辑后，尚未保存的修改会丢失。现有草稿机制仅服务于新增储蓄，并刻意跳过了带目标 ID 的编辑状态。

## 目标

为每个已存在的储蓄总目标提供独立的本地实时草稿。重新打开同一目标时恢复其未提交修改；编辑另一个目标时不会串入错误数据；成功保存后只清理当前目标的草稿。

## 实施步骤

- [x] 梳理储蓄规划器现有草稿读取、保存和清理条件。
- [x] 为统一草稿存储增加可选作用域，并保持新增储蓄的原有键不变。
- [x] 让储蓄目标编辑器按目标 ID 保存和恢复草稿。
- [x] 在编辑保存成功后仅清理当前目标的草稿。
- [x] 补充草稿键隔离的回归测试。
- [x] 运行测试、类型检查和生产构建。
- [x] 更新版本记录并完成本地 Git 提交。

## 验收标准

1. 编辑目标 A 后关闭，重新编辑目标 A 时会恢复未保存内容。
2. 编辑目标 B 时不会看到目标 A 的草稿。
3. 新增储蓄继续使用原有草稿，不受编辑草稿影响。
4. 保存目标 A 后只删除目标 A 的草稿。
