# Web 财务页面个性化设计

版本：`0.0.54`

## 目标

让消费、贷款、资产三个页面在保持液态玻璃体系一致的前提下，拥有不同的顶部信息结构和视觉性格。

## 设计方向

1. 消费页：纵向月度票据。通过总额、渠道明细、最高分类和结算区形成自上而下的票据阅读顺序。
2. 贷款页：还款节点控制台。通过待还本金、下一节点、十段进度和压力指标形成横纵混合的控制台结构。
3. 资产页：资产负债等式。通过资产减负债的逐行算式得到净资产，形成正式账表结构。

## 0.0.53 贷款页视觉收束

- 深色还款节点控制台保留独立身份，补充深蓝灰玻璃层和绿色环境光，改善核心金额与下一节点的阅读关系。
- 十段还款进度、还款日程节点、贷款组合进度条和新增贷款操作区统一为更轻的高光、渐变和状态层级。
- 只调整贷款页 CSS 与窄屏适配，不改变数据仓库、统计口径、排序和保存逻辑。

## 0.0.54 资产页层级收敛

- 资产页以净资产主卡为唯一视觉焦点，资产总额和负债总额退为辅助指标。
- 资产构成与流动性、负债率、集中度合并到单层结构总览中，减少连续小卡片造成的噪音。
- 资产与负债改为单列分组明细，保留完整数据但取消移动端双栏挤压。
- 新增资产表单保留在页面底部，作为独立、低权重的操作区。

## 约束
1. 不修改数据仓库和统计口径。
3. 顶部保持单层主容器，避免内外双重描边和卡片套卡片。
4. 保持窄屏可用，不产生横向滚动和文字溢出。
