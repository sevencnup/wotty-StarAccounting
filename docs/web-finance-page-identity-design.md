# Web 财务页面个性化设计

版本：`0.0.51`

## 目标

让消费、贷款、资产三个页面在保持液态玻璃体系一致的前提下，拥有不同的顶部信息结构和视觉性格。

## 设计方向

1. 消费页：消费脉搏。使用浅暖色账单面板，突出支出金额、流水数量和支付渠道。
2. 贷款页：还款指挥台。使用深色高对比面板，突出待还本金、整体进度和偿还压力。
3. 资产页：资产负债表。使用浅绿色账本面板，突出净资产以及资产与负债的关系。

## 约束

1. 不修改数据仓库和统计口径。
2. 不使用三个页面共用的同款顶部布局。
3. 顶部保持单层主容器，避免内外双重描边和卡片套卡片。
4. 保持窄屏可用，不产生横向滚动和文字溢出。
