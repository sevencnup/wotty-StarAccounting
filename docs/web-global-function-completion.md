# 全局功能补齐开发文档

## 目标

按用户确认的优先级，补齐账本上下文、资产/贷款/流水管理、预算入口、设置页语义、导入错误处理、储蓄年份与贷款统计月份、批量查询与页面缓存，并增加关键页面交互测试。

- [x] 增加资产、贷款、流水的编辑和删除入口。
- [x] 增加最小可用预算管理页面（总预算、月度/年度、预警比例、编辑删除）。

## 约束

- 不自动打包或安装 APK。
- 保留工作区中与本任务无关的已有修改。
- 不使用破坏性 Git 操作。
