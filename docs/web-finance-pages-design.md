# Web 财务分页面设计

版本：`0.0.53`

## 目标

将贷款、资产、账户从同构的“汇总 + 表单 + 列表”页面，重构为职责清晰的三个财务工作台。全部指标读取现有数据库，不引入演示回退数据。

## 统一设计语言

1. 使用纯白背景、蓝灰主色、细边框和 10-14px 圆角，不使用卡片阴影。
2. 金额统一使用等宽数字特性，正向数据使用绿色，负债和风险使用珊瑚红，提醒使用琥珀色。
3. 页面顶部保留统一标题栏；卡片标题、说明、空状态和按钮遵循现有字号层级。
4. 移动端优先，所有双列与多列内容在 430px 页面宽度内完整显示。

## 贷款页：还款节奏

1. 债务仪表盘展示剩余本金、本月月供、整体还款进度和待还期数。
2. 最近还款节点按距到期日排序，显示剩余天数、金额和风险状态。
3. 还款压力模块使用本月真实收入计算月供收入比，无收入时明确显示暂无口径。
4. 贷款清单使用独立进度卡，展示已还/剩余、期数和下期还款日。
5. 新增贷款表单置于页面末尾，避免打断查看任务。

## 本次贷款页 UI 优化（0.0.53）

- 保留深色“还款指挥台”作为贷款页独立视觉身份，优化待还本金与下一还款节点的空间比例，并增加轻量绿色环境光和内层层次。
- 十段整体还款进度改为带顶部高光的绿色渐变段，强化完成状态但不改变原有百分比计算。
- 还款日程增加节点、行距和状态对比，临近还款继续使用提醒色，贷款排序和文案保持不变。
- 贷款组合卡统一为浅色液态玻璃内层，进度条与储蓄/预算保持 8px 渐变高光样式。
- 新增贷款区域增加玻璃输入控件、聚焦反馈和渐变主按钮，字段、保存流程和数据仓库调用保持不变。
- 在 420px 与 370px 窄屏下补充金额、节点和指标的紧凑适配，避免横向溢出。

## 账户页：应用设置中心

1. 页面采用分组白色圆角列表，每项使用独立彩色图标、当前状态和右侧箭头。
2. 数据与同步组提供本地/云端模式切换，以及微信、支付宝 CSV 账单导入。
3. 显示偏好组提供主题、语言和字体大小设置，并在本机持久保存。
4. 支持组提供帮助与反馈和关于信息。
5. 每项设置使用统一底部面板承载详细内容，账户页不显示全局记账浮动按钮。
6. 微信与支付宝账单采用独立选择入口和解析器，平台格式不匹配时禁止导入。
7. 云端模式提供服务地址、连接状态、测试连接和确定按钮，连接测试成功后才允许保存并切换。

## 验证

1. 无数据、单条数据和多条数据均不产生无效百分比或布局溢出。
2. 三个页面的加载状态可结束，远程失败时使用仓储层返回的空数组。
3. 类型检查、现有测试、生产构建和移动端浏览器截图全部通过。
4. 账单导入覆盖微信、支付宝及错选平台场景；模式切换覆盖连接失败、未测试拦截、连接成功和配置持久化场景。
