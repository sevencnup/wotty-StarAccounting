# API 性能优化开发方案

## 目标

- 降低 API 启动和数据库连接初始化开销。
- 优化云端同步、账单分页和按月查询的数据库访问路径。
- 保持现有认证、账户隔离和数据格式不变。

## 实施步骤

1. 统计现有 API 启动日志、主要 SQL 查询和数据库索引，确认优化目标。
2. 为账单按账本/日期、同步实体按账本等高频查询补充合适索引。
3. 避免同步接口在一次请求中重复扫描无关数据，保持账户归属过滤在数据库查询层完成。
4. 将连接池参数改为可通过环境变量调整，并设置适合单机部署的默认值。
5. 执行 API 测试、Web 类型检查和启动健康检查。

## 验收标准

- 不改变 LOCAL/CLOUD 模式、认证和账户隔离行为。
- API 能自动补齐新增索引，不删除已有数据。
- 默认配置适合当前个人/小型部署，生产环境可通过环境变量扩容连接池。
- 现有测试全部通过，健康检查返回 `db: true`。
