# 底部弹层侧滑返回保护开发记录

## 目标

在 Web 与 Android WebView 中打开底部弹层后，边缘侧滑返回只关闭当前弹层，不切换底层主页面。

## 实施步骤

- [x] 排查公共底部弹层、页面路由及 Android WebView 的返回调用链。
- [x] 确认单纯的同 URL 历史状态在部分浏览器/WebView 返回栈中不足以稳定隔离页面导航。
- [x] 为弹层建立带 hash 的独立历史哨兵，确保系统返回先回到同一页面。
- [x] 通过历史哨兵消费系统/浏览器边缘返回，避免手动手势与浏览器返回叠加。
- [x] 在实际抽屉滚动容器上禁用横向内容手势，同时保留纵向滚动。
- [x] 侧滑返回后保留抽屉遮罩至关闭动画结束，避免手势收尾事件穿透到底部导航。
- [x] 执行类型检查、测试、生产构建和差异校验。

## 验收标准

1. 打开预算管理后，从左侧或右侧边缘向内侧滑只关闭预算管理。
2. 关闭预算管理后，当前主页面路径与选中的底部导航项保持不变。
3. 正常返回操作在没有打开弹层时仍保持原有行为。
