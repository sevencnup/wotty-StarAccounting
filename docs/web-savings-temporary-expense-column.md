# 储蓄计划临时支出列开发文档

## 问题

储蓄计划表中的新增支出列会在第一行输入后同步到所有月份，适合房租等固定支出，但不适合每月金额不同的临时支出。

## 目标

增加临时支出列。临时支出可以在任意月份的单元格单独填写，不向其他月份同步，同时继续参与每行剩余金额、年度预计存和保存恢复。

## 实施步骤

- [x] 区分固定支出列和临时支出列，并兼容旧版计划配置。
- [x] 增加“新增固定支出”和“新增临时支出”按钮。
- [x] 保持固定支出首行输入同步，临时支出只更新当前单元格。
- [x] 将临时支出纳入每行剩余金额与年度汇总。
- [x] 增加固定列同步、临时列独立输入和临时金额计算测试。
- [x] 运行类型检查、测试和生产构建。
- [x] 更新版本记录并完成本地 Git 提交。

## 验收标准

1. 新增固定支出后，第一行输入仍会同步到全部月份。
2. 新增临时支出后，可在任意月份单独填写金额，其他月份不自动跟随。
3. 临时支出会计入对应月份的“剩余”金额、年度预计存汇总和保存内容。
4. 旧储蓄计划打开后不丢失已有支出列。
