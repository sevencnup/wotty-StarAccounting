# 首页薪资收入批量补录开发文档

## 目标

在首页“添加薪资收入”打开的记账面板中保留单月录入，并新增批量补录功能，让用户能够指定年份、选择多个月份和统一金额，一次补齐历史账单缺失的工资收入。

## 范围

- 在工资预设记账面板中提供“单月录入 / 批量补录”切换。
- 批量补录可设置年份、一个或多个目标月份、每月工资金额、入账账户和发薪日。
- 每个选中月份生成一笔“收入 / 工资”流水。
- 已经存在工资收入的月份自动跳过；同一批次使用稳定订单号避免重复写入。
- 支持本地模式 IndexedDB 与云端模式 API，成功后刷新首页统计。

## 验收标准

1. 首页“添加薪资收入”仍默认打开单月工资录入。
2. 用户可切换到批量补录，设置年份并任选多个月份。
3. 点击保存后，每个选中月份生成一笔金额一致的工资收入，日期为该月设定发薪日。
4. 目标月份已有工资收入时不重复新增，并在结果中告知跳过数量。
5. 本地和云端模式均可写入，首页收支统计会刷新。
