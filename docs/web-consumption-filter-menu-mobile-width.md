# 消费筛选下拉菜单移动端宽度优化开发文档

## 问题

消费页面的“分类”和“账户”自定义下拉菜单在手机与 Capacitor App 中沿用了筛选按钮宽度，浮层过窄，选项名称和数量容易被截断。

## 目标

移动端打开筛选菜单时使用接近屏幕可用宽度的浮层，同时保留桌面端的紧凑布局、定位和滚动行为。

## 实施步骤

- [x] 让分类/账户菜单在移动端不再跟随触发按钮变窄。
- [x] 通过移动端 CSS 固定左右安全边距，并覆盖触发器的窄内联宽度。
- [x] 运行测试、类型检查和生产构建。
- [x] 完成本地 Git 提交。

## 验收标准

1. 手机和 App 中分类、账户下拉浮层宽度至少覆盖主要内容，最长名称不因按钮宽度被截断。
2. 浮层不会超出屏幕左右边界，并保持当前定位、点击外部关闭和列表滚动。
3. 桌面端筛选菜单行为与原来一致。

## 版本记录

本次为移动端筛选浮层的小型布局调整，不新增版本号。
