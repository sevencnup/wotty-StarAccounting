# 消费筛选下拉菜单移动端宽度优化开发文档

## 问题

消费页面的“分类”和“账户”自定义下拉菜单在手机与 Capacitor App 中沿用了筛选按钮宽度，浮层过窄，选项名称和数量容易被截断。

## 目标

移动端打开筛选菜单时让浮层宽度与对应的分类/账户筛选按钮一致，同时保留屏幕边界保护、定位和滚动行为。

## 实施步骤

- [x] 让分类/账户菜单宽度与对应触发按钮保持一致。
- [x] 保留 JavaScript 的屏幕边界保护，移除移动端全宽 CSS 覆盖。
- [x] 根据移动端示意图确认浮层不再使用全宽布局。
- [x] 运行测试、类型检查和生产构建。
- [x] 完成本地 Git 提交。

## 验收标准

1. 手机和 App 中分类、账户下拉浮层与对应筛选按钮等宽。
2. 浮层不会超出屏幕左右边界，并保持当前定位、点击外部关闭和列表滚动。
3. 桌面端筛选菜单行为与原来一致。

## 版本记录

本次为移动端筛选浮层的小型布局调整，不新增版本号。
