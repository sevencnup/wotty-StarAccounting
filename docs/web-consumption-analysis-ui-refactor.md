# Web 消费分析页 UI 重构开发文档

## 1. 目标
将消费页从“图表连续堆叠”调整为分析与明细中心，统一首页和记账面板的 Stark 浅色视觉语言：
- 顶部展示本月支出、日均支出、结余和记录数。
- 增加支出/收入、平台和关键词筛选，筛选结果同时驱动图表与流水。
- 保留趋势、分类结构和消费日历作为核心分析。
- 平台支出与消费流向降级到可展开的深入分析区。
- 将流水明细保留在消费页底部，作为该页面的主要操作内容。

## 2. 实施步骤
- [ ] 重构 `web/src/app/(tabs)/consumption/page.tsx` 的总览和筛选状态。
- [ ] 重构 `web/src/components/stark/ConsumptionCharts.tsx` 的分析层级。
- [ ] 更新 `web/src/app/globals.css` 的消费页、筛选栏和明细样式。
- [ ] 运行 `pnpm build` 验证编译和类型。
- [ ] 更新文档并完成本地 Git 提交。

## 3. 验收标准
1. 首屏信息层级清晰，浅色总览卡与首页风格一致。
2. 筛选条件能同步影响统计、图表和流水列表。
3. 深入图表默认收起，不增加首屏负担。
4. 小屏无横向溢出，构建通过。
