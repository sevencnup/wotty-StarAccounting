# 储蓄目标级联删除开发文档

## 目标

- 在已添加储蓄目标的编辑页面提供删除目标按钮。
- 删除前清楚提示该操作会同时删除目标下全部月度储蓄计划，并要求二次确认。
- 本地与云端数据源都以原子方式删除目标及其关联月度计划，避免残留计划或半删除状态。
- 删除成功后清理对应编辑草稿、刷新储蓄页面并关闭编辑面板。

## 实施步骤

1. 将现有“删除储蓄目标”操作统一为级联删除，并分别实现本地 IndexedDB 与远端 API 调用。
2. 在 API 的既有删除接口中，在数据库事务内先删除计划、再删除目标，并保留当前用户账本权限保护。
3. 在储蓄目标编辑面板增加危险操作区、计划数量提示、二次确认和提交中状态。
4. 删除成功后清理该目标草稿并触发储蓄页刷新；失败时保留目标并展示错误信息。
5. 增加针对级联删除接口和目标编辑删除逻辑的测试，执行前后端校验、生产构建和差异检查。

## 验收标准

- 新建中的未保存储蓄计划不显示删除目标按钮。
- 已保存目标显示删除按钮，确认文案包含受影响的月度计划数量。
- 成功后目标和全部关联 `SavingsPlan` 均不可再查询。
- 取消确认或删除失败不会关闭编辑面板；云端操作只影响当前用户拥有的目标。
