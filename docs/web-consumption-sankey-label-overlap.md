# 消费页桑基图标签重叠修复

## 目标

修复消费页桑基图在微信、支付宝同时出现时，账户标签纵向排布过近或重叠的问题。

## 实施步骤

- [x] 为桑基图布局参数增加回归测试。
- [x] 启用 ECharts 节点布局迭代，并调整节点间距。
- [x] 运行消费页相关测试、类型检查和生产构建。
- [x] 更新版本记录并完成本地 Git 提交。

## 规则

- 微信、支付宝等账户节点必须拥有可读的独立标签区域。
- 桌面端和窄屏端继续使用现有横向桑基图，不改变数据流向。
- 修复只影响图表布局，不改变流水统计。

## 版本记录

### 0.0.94

修复消费页桑基图账户标签重叠。

### 0.0.95

收紧微信、支付宝等账户节点的纵向布局，避免自动松弛把节点拉到图表两端。

### 0.0.96

修正账户节点与连线的布局基准，改为仅避让标签文字，避免微信和支付宝方块及连线出现视觉合并。

### 0.0.97

修正多分类场景下节点间距过大导致桑基图节点高度异常的问题。

### 0.0.98

将账户名称移至图表标题区的图例，图内仅保留不重叠的分类标签并限制在图表范围内。

### 0.0.99

恢复桑基图自动节点排布，修正节点被压缩到图表顶部的问题。
