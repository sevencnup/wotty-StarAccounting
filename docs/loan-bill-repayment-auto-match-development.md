# 账单自动匹配贷款还款开发文档

## 目标

- 导入微信、支付宝账单时，自动识别已配置贷款对应的还款流水。
- 仅在账单同时包含还款语义和贷款匹配信息时建立关联，避免把普通消费误扣为还款。
- 对成功导入且关联贷款的流水，自动写入 `loanId`、标为“还款”，并减少贷款待还金额及已还期数。
- 本地 IndexedDB 与云端 MySQL 均保证“导入流水与更新贷款”在同一事务中完成；重复导入不能重复冲销。

## 实施步骤

1. 新增纯前端匹配规则：以贷款名称和可选匹配关键词，在账单的商户、商品备注、付款方式中识别还款流水；匹配不唯一时不自动关联。
2. 在贷款编辑表单中暴露“账单匹配关键词”，用于区分同一机构下的多笔贷款。
3. 扩展批量导入仓储接口：只对本次实际新增的关联流水更新贷款，更新金额不超过待还金额，并同步还款期数与结清状态。
4. 本地模式使用单个 IndexedDB 写事务；云端模式由 API 在单个数据库事务中完成去重、写流水和更新贷款。
5. 导入完成提示新增自动关联的还款笔数和金额，并刷新相关数据缓存。
6. 为匹配规则和导入冲销边界补充测试，执行类型检查、前端测试、生产构建和差异检查。

## 验收标准

- “招商银行还款”等同时命中贷款名称与还款语义的账单，会显示为还款并关联到该笔贷款。
- 普通消费、没有还款语义的交易、或命中多笔贷款的交易不会自动冲销贷款。
- 再次导入同一订单号只会跳过，不会第二次减少贷款。
- 一次导入多笔还款时，待还金额不会为负，已还期数不会超过总期数，余额归零时贷款自动标为已结清。
- 本地和云端任一导入失败时不会出现“流水已写入、贷款未更新”或相反的半完成状态。
