# 移除重复储蓄目标卡片开发记录

## 目标

移除储蓄页面中与“目标组”重复展示的“当前冲刺目标”模块，避免同一个储蓄目标在页面中出现两次。

## 实施步骤

- [x] 确认“当前冲刺目标”和“目标组”是否读取同一数据。
- [x] 移除重复的“当前冲刺目标”卡片。
- [x] 保留顶部储蓄总览和目标组数据展示。
- [x] 运行类型检查、测试和生产构建。
- [x] 更新版本记录并完成本地 Git 提交。

## 验收标准

1. 储蓄页面不再显示“当前冲刺目标”重复模块，目标组作为唯一目标明细区域。
2. “目标组”仍正常显示用户创建的储蓄目标。
3. 顶部储蓄总览不受影响。
4. 不删除或修改任何储蓄目标数据。
