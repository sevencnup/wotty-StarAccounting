# 消费明细操作按钮布局修复

## 目标

修复消费页面流水明细中新增的“编辑/删除”按钮被 Grid 自动换到下一行，并在窄列中出现竖排的问题。

## 实施步骤

- [x] 检查消费明细 JSX 与全局 `.recent-row` 网格定义。
- [x] 为消费明细单独增加操作列，保持编辑和删除按钮与流水内容同一行。
- [x] 禁止操作按钮文字换行，并增加小屏列宽适配。
- [x] 运行 Web 测试、类型检查和生产构建。
- [x] 完成本地 Git 提交。

## 验收标准

1. 消费明细每行的编辑、删除按钮不再掉到下一行。
2. 操作按钮文字保持横向显示。
3. 360px 及以上移动端宽度不发生明显横向溢出。
