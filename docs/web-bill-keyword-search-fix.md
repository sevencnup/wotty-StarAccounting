# 账单关键词搜索修复开发文档

## 目标

修复账户页「账单归类」中的账单关键词无法搜出已导入流水的问题，使输入关键词后能立即展示当前账本全部匹配的非收入流水，并确保批量归类作用于相同范围。

## 已确认原因

归类面板将账本固定为 `default`，初次只加载前 200 笔流水；关键词输入只更新匹配数量，不会筛选、展示命中的流水。非默认账本、较早的账单或用户期望直接搜索时，都会表现为搜不到。

## 实施步骤

- [x] 建立关键词匹配与可归类流水筛选的回归测试。
- [x] 归类面板读取当前账本的完整流水与规则。
- [x] 输入关键词时实时显示全部命中流水，并保留无关键词时的转账/全部筛选。
- [x] 运行测试、类型检查与生产构建。
- [x] 完成本地 Git 提交。

## 验收标准

1. 输入商户、商品说明、备注、平台、支付方式或订单号中的关键词后，马上能看到匹配流水。
2. 搜索不受初次 200 笔加载上限影响。
3. 搜索和规则保存均使用当前账本。
4. 输入为空时，仍可通过「转账 / 全部流水」查看待归类账单。
