# 首页添加薪资收入点击延迟修复开发文档

## 问题

首页顶部卡片的“添加薪资收入”按钮通过路由跳转打开记账页。首次加载记账页时需要等待页面代码编译和挂载，点击后约一秒才显示表单。

## 目标

复用 tabs 布局中已经加载的记账面板，让首页工资入口即时显示收入/工资预设表单，同时保留独立 `/journal?preset=salary` 地址的原有行为。

## 实施步骤

- [x] 建立首页点击到记账面板显示的浏览器计时复现。
- [x] 将首页工资入口改为触发共享布局内的记账面板。
- [x] 保留收入类型和工资分类预设。
- [x] 验证关闭、浏览器返回和独立记账路由行为。
- [x] 运行类型检查、测试和生产构建。
- [x] 完成本地 Git 提交。

## 验收标准

1. 首页点击“添加薪资收入”后立即显示记账面板。
2. 面板默认选中“收入”和“工资”。
3. 面板关闭或浏览器返回后仍停留在首页。
4. 直接访问 `/journal?preset=salary` 仍然可以打开相同预设。
