# 项目使用文档调整

版本：`0.0.1`

## 目标

将根目录 `CHANGELOG.md` 调整为面向使用者的项目介绍与使用教程，并将历史版本记录迁移到独立文档，避免项目介绍与开发记录混在同一文件中。

## 执行步骤

1. 将现有版本记录迁移到 `docs/version-history.md`。
2. 重写 `CHANGELOG.md`，补充项目结构、环境要求、开发启动、数据库配置、云端/本地模式和常见问题。
3. 使用仓库现有脚本和端口信息校对命令，不写入未实现的 Docker 或部署命令。
4. 执行 Markdown 差异检查并创建本地提交，不推送 GitHub。

## 验收标准

- `CHANGELOG.md` 不再包含版本记录标题或版本条目。
- 新用户可按文档启动 Web 与 API 服务。
- 数据库配置与现有 `api-server` 行为一致。
- 原版本记录仍可在独立文档中查阅。
