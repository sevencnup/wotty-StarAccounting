# Web 账单导出与端形态说明

## 目标

在设置页增加当前账本流水导出能力，并在帮助与反馈中说明 Web 端与 Android App 的定位差异。

## 实施步骤

- [x] 增加账单 CSV 序列化工具，保留主要流水字段并兼容 Excel/WPS。
- [x] 在设置页增加“导出账单”入口，导出当前账本全部流水。
- [x] 在帮助页增加“Web 端和 App 有何不同？”说明。
- [x] 补充导出工具回归测试。
- [x] 运行测试、类型检查和生产构建。
- [x] 更新版本记录并完成本地 Git 提交。

## 规则

- 导出范围按当前账本 `accountId` 隔离，不导出其他账本数据。
- 导出格式为 UTF-8 BOM CSV，所有字段统一转义双引号、逗号和换行。
- 导出只下载文件，不修改本地或云端数据。
