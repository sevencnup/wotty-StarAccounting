# Web 局域网开发页面水合修复开发文档

## 问题

手机通过局域网地址访问 Web 开发服务器时，首页、消费、储蓄、贷款和资产页持续显示骨架屏；账户页虽可显示静态内容，但按钮没有响应。

## 目标

让 Next.js 开发服务器信任本机当前局域网 IPv4 地址的开发资源请求，使手机端的 HMR WebSocket 能建立连接并正常完成 React 水合、页面交互和数据加载。

## 实施步骤

- [x] 用局域网地址与 localhost 对比复现，确认远程页面无法水合。
- [x] 验证 API 健康检查、业务接口和 CORS 响应正常，排除后端不可访问。
- [x] 捕获开发服务器 HMR WebSocket 返回 `Unauthorized`，确认 Next.js 开发来源保护为根因。
- [x] 在 Next 配置中自动读取本机非回环 IPv4 地址，作为 `allowedDevOrigins`。
- [x] 重启开发服务器并用真实浏览器回归局域网页面水合、交互和数据请求。
- [x] 运行类型检查与生产构建。
- [x] 更新版本记录并完成本地 Git 提交。

## 验收标准

1. 手机可通过当前局域网 IP 打开 Web 开发服务器，HMR WebSocket 不再返回 `Unauthorized`。
2. 首页不再持续显示骨架屏，并能请求 API 数据。
3. 账户页的“切换模式”按钮可打开设置抽屉。
4. 类型检查和生产构建通过。
