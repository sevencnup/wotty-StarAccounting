# 消费页账户下拉菜单 UI 优化开发文档

## 目标

将消费分析页筛选栏中的“账户”原生下拉菜单替换为与分类菜单一致的自定义浮层，解决系统默认灰色选中态、样式不可控和移动端体验不统一的问题。

## 实施步骤

- [x] 将账户原生 select 替换为 Portal 自定义菜单。
- [x] 为账户项增加账户图标、流水数量和选中态。
- [x] 支持点击选择、点击外部关闭和 Esc 关闭。
- [x] 保持账户筛选逻辑不变，并与分类菜单互斥打开。
- [x] 完成类型检查、构建和移动端交互检查。
- [x] 更新版本记录并完成本地 Git 提交。

## 验收标准

1. 账户菜单不再显示浏览器默认灰色下拉层。
2. 菜单视觉与分类菜单统一，当前账户有明显高亮和勾选标记。
3. 账户菜单显示各账户的流水数量，手机宽度下不横向溢出。
4. 选择账户后，图表和流水明细仍按原有账户筛选逻辑更新。
5. pnpm typecheck 与 pnpm build 通过。
