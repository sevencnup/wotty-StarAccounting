# 首页图表 ECharts 统一开发文档

## 目标

- 将首页仍由 CSS/React 绘制的支出结构图与收支走势柱图统一为 ECharts。
- 支出结构使用 ECharts 南丁格尔玫瑰图，以图外引导线展示分类标签；保持颜色、空数据状态和月份详情交互不变。
- 复用现有 `EChartView` 的动态模块加载与视口可见后初始化机制，避免影响首页首屏加载。

## 实施步骤

1. 为首页支出结构生成 ECharts 南丁格尔玫瑰图配置，保留分类颜色并以图外引导线展示数据标签。
2. 将首页收支走势的手写柱图替换为 ECharts 双序列柱图，保留收入/支出图例与点击月份显示详情的能力。
3. 为共享 `EChartView` 增加安全的图表点击回调支持，供首页趋势图读取被点击的数据索引，不影响现有图表调用。
4. 清理已替换图表的 CSS 绘制规则，更新版本记录并执行类型检查、测试和生产构建。

## 验收标准

- 首页支出玫瑰图和收支走势均通过 `EChartView` 渲染。
- 图表仅接近视口时初始化 ECharts；不会在页面加载时同步创建画布。
- 点击趋势中的月份仍能查看对应月份收入和支出详情。
- 消费、资产、贷款页面既有 ECharts 图表不受影响。
