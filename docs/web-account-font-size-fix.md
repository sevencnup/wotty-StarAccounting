# 账户页字体大小功能修复开发文档

## 问题

账户页的字体大小选项可以写入本地设置并更新 `data-font-size`，但页面中绝大多数文字使用固定像素值，导致切换“较小/标准/较大”后只有少量设置文字变化，实际应用体验没有整体改变。

## 目标

让账户页字体大小设置真正作用于 Web 应用界面，支持即时切换、刷新后保持，并确保设置面板、底部导航和固定定位浮层布局不发生明显错位。

## 实施步骤

- [x] 通过浏览器验证字体选项、持久化设置和实际计算字体大小。
- [x] 将字体大小比例应用到已加载的应用界面。
- [x] 验证小号、标准、大号三种状态及刷新恢复。
- [x] 运行测试、类型检查和生产构建。
- [x] 更新版本记录并完成本地 Git 提交。

## 验收标准

1. 选择“较小”后，账户页主要文字和导航文字整体缩小。
2. 选择“较大”后，账户页主要文字和导航文字整体放大。
3. “标准”恢复默认大小。
4. 刷新页面后仍保留已选择的字体大小。
5. 设置面板可以正常打开、关闭，页面不出现横向溢出。
