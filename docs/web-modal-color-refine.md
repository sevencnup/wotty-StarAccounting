# 记账弹窗中性色与主操作质感优化开发文档

## 1. 需求与问题诊断

在去除青色背景与边框后，部分控件（如主操作按钮、选中状态药丸、分类选中等）采用了 `#334155` 等水泥灰/暗灰色，导致视觉整体发灰、暗淡且类似禁用态（disabled），缺乏视觉重心与精致感。

本次优化目标：
- 主操作按钮（保存记账、保存贷款、保存资产等）采用标准纯净的品牌蓝 `#0060c0`（纯色无渐变），清晰醒目、富有确定感。
- 金额展示大屏与货币符号统一为深邃黑 `#0f172a`，输入框数字对比清晰，告别发灰模糊感。
- 选中的分类图标与支付账户：去除脏灰底色，采用深色质感或品牌蓝高亮，分类图标正常显示不反色发白。
- 保持整体纯白、无渐变、无青色塑料感的现代纯净风格。

## 2. 影响范围

- `docs/web-modal-remove-cyan-style.md` / `docs/web-modal-color-refine.md`
