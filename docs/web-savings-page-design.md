# Web 储蓄页液态玻璃设计

## 目标

在不改变储蓄数据、计算和交互的前提下，让储蓄页与首页保持同一套液态玻璃视觉语言，适配 420px 移动端。

## 本次调整

- 顶部“储蓄总览”保留浅薄荷色语义，但改为白色/浅绿色半透明渐变、内高光、低强度阴影和 `backdrop-filter` 玻璃层；左侧装饰色条不再显示。
- 三项关键指标改为轻量内层玻璃卡，使用半透明背景、细白边和内高光，避免三个模块看起来像不透明色块。
- “目标组”和“月度节奏”外层卡统一为 22px 圆角、白色渐变玻璃、内高光和柔和阴影；目标卡、月度卡片作为更浅的内层玻璃。
- “最近计划”卡与其他外层卡统一玻璃背景；最近计划行保留金额右侧对齐，并改为轻量玻璃内层。
- 目标进度条和月度节奏条统一为 8px 轨道，加入首页同款顶部微光罩层；绿色仍表示已完成/储蓄进度，蓝色仍表示计划范围。
- 环形总进度继续保留绿色，不改变百分比计算。

## 不改

- `web/src/app/(tabs)/savings/page.tsx` 的数据和 JSX。
- 储蓄计划编辑、浮动记账面板、底部导航。
- Android 与其他页面业务逻辑。

- `web/src/app/globals.css`

## 验证

- `web` 目录 `pnpm typecheck` 通过。
- Playwright 以 420×900 访问 `/savings`：页面无横向溢出，顶部总览、指标、目标、节奏、最近计划均有玻璃背景与阴影层次。
- 环形进度与目标/节奏进度条保留绿色语义，最近计划金额保持右对齐。
- 已知的本地 8080 `api-sync` 连接失败不属于本次页面改动。
