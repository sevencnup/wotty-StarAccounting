# 添加储蓄页面月份行与上月结余列开发文档

## 目标

在添加储蓄页面中，让单月存和隔月存两种模式的月份行都可以删除；增加“上月结余”列，并让该列参与当前行剩余金额的计算与储蓄计划保存。

## 实施步骤

- [x] 梳理储蓄规划器的月份行生成、编辑、保存和恢复逻辑。
- [x] 为两种模式增加可删除月份行的状态与操作入口，并保证至少保留一行可编辑月份。
- [x] 增加“上月结余”列按钮、输入和计算逻辑。
- [x] 更新本地草稿、远端保存和删除行后的月份计划数据处理。
- [x] 补充或更新测试，验证两种模式和上月结余列。
- [x] 运行类型检查、测试和生产构建。
- [x] 更新版本记录并完成本地 Git 提交。

## 验收标准

1. 单月存模式的任意月份行可以删除，删除后表格和保存数据同步更新。
2. 隔月存模式的任意月份行可以删除，删除后表格和保存数据同步更新。
3. 两种模式至少保留一行，删除最后一行时不会出现不可编辑的空表。
4. 页面提供添加“上月结余”列的按钮，列可输入金额并参与剩余金额计算。
5. 上月结余列配置和数据可通过本地草稿恢复，并可随储蓄计划保存。
6. 既有固定支出、临时支出和两种储蓄频率行为不回归。
