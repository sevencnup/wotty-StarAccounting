# 已添加储蓄目标编辑功能开发文档

## 目标

为储蓄页面已存在的储蓄目标增加编辑入口，使用户可以重新打开目标并修改目标基本信息与储蓄计划。

## 实施步骤

- [x] 梳理储蓄目标列表、添加储蓄路由和储蓄规划器的数据流。
- [x] 增加从目标列表进入编辑状态的入口，并传递目标 ID。
- [x] 让储蓄规划器按目标 ID 加载对应目标，而不是始终加载第一个目标或创建新目标。
- [x] 保存编辑后的目标信息和储蓄计划，保持已有目标 ID、记录状态及月份数据。
- [x] 补充回归测试并验证新增目标流程不受影响。
- [x] 运行类型检查、测试和生产构建。
- [x] 更新版本记录并完成本地 Git 提交。

## 验收标准

1. 已添加的储蓄目标列表提供明确的编辑入口。
2. 进入编辑后会回填目标名称、目标金额、截止日期、存储类型及储蓄计划。
3. 保存后更新原目标，不会重复创建一个新目标。
4. 原有月份删除、上月结余、固定/临时支出和双语功能不回归。
5. 新增储蓄目标仍可正常创建。
