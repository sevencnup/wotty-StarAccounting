# 储蓄凭证预览与云端缓存升级

## 目标

- 提高底部“记账/添加储蓄”等悬浮按钮，避免与底栏重叠。
- 允许在储蓄计划的已存记录及编辑面板查看凭证大图。
- 为云端响应缓存建立独立的数据格式版本；客户端格式变化时自动跳过旧缓存，重新从云端读取。

## 实施步骤

1. 调整悬浮按钮相对底栏的间距，兼顾安全区域与 KT 混合版底栏。
2. 增加可关闭的图片大图预览，在储蓄计划列表与记录编辑面板接入。
3. 为云端缓存记录保存数据格式版本，读取时忽略不匹配的记录；每次启动首次读取缓存后后台刷新。仅当客户端接口模型变化时递增该版本。
4. 更新版本记录并提交本地仓库。

## 边界

云端 MySQL 的建表和迁移由服务端负责。客户端只缓存 API 响应；安装 APK 不会复制或迁移云端数据库，也不会把云端账本写进本地模式账本。云端 API 在旧客户端无法兼容时仍需服务端兼容处理或发布新版客户端。
