# 纯 Kotlin 预算管理

## 目标

对照 Web `BudgetManagementSheet`，把原生首页的“预算管理”入口从单一月预算输入改为总预算管理。支持月度/年度总预算的新增、编辑、删除和提醒比例设置；按当前本地账本或云端账本保存，操作失败时保留表单并说明原因。

## Web 行为与原生差异

- Web 预算页通过 `getBudgets(accountId)` 读取当前账本预算；预算实体含 `id/userId/accountId/amount/category/period/alertPercent/platform/scopeType/createdAt/updatedAt`。
- 当前 Web 管理界面只开放总预算，支持每月或每年以及 1–100% 提醒比例；分类预算和平台预算明确留待以后扩展，本轮不提前增加这两种配置。
- Web 保存和删除分别调用 Repository 的 `saveBudget` / `deleteBudget`。云端 API 已有 `/api/budgets` GET、POST、DELETE；原生已有读取接口，但模型字段不完整，也缺少写删接口。
- 原生“预算管理”现在打开资金概览对话框，只能编辑一个 SharedPreferences 月预算；预算列表只在云端读取，且未进入独立 SQLite 实体缓存，不能在本地模式管理或持久化多个预算。
- 首页资金分配、诊断和预算余量罗盘混用旧月预算偏好与云端月度预算；需统一使用当前账本内的全局月度预算，保留旧本地月预算数据迁移能力，并隔离云端账户与本地账本。

## 实施步骤

1. 建立与 Web 字段一致的 `NativeBudget` 模型和 JSON 转换；使用 `NativeEntityDatabase` 的 `budgets` 类型读写本地数据，并按 `LOCAL/CLOUD + accountId` 隔离。
2. 为 `NativeApiClient` 补齐预算保存和删除；云端操作只有服务器成功后才更新本地缓存和 Compose 状态，失败时保留数据并显示错误。
3. 将旧版仅本地保存的月预算一次性迁移为当前本地账本的月度全局预算，保留金额、默认 80% 提醒比例和原创建时间可用信息；云端账本不得读取或迁入本地偏好。
4. 将首页预算入口替换为预算管理面板，复刻 Web 列表、空状态、创建/编辑表单、周期选择、提醒比例滑杆、保存校验、删除二次确认和加载/错误反馈。
5. 首页资金分配、财务诊断、预算余量显示使用当前账本的月度全局预算和本月支出；没有月度预算时按 Web 首页现有逻辑使用当期收入作为分配基数。预算实体的年度周期保留在管理列表中，不错误地当成月预算。
6. 补充中英文文案与版本记录，版本按新增功能递增；构建并安装独立调试包，在真机验证本地新增、编辑、比例、删除、重启持久化及首页联动。云端未登录时明确记录为未验收。
7. 更新完整开发计划和本文件验收记录；检查 `git diff --check`，只将本轮源码、版本和开发文档提交到本地 Git，不推送 GitHub。
