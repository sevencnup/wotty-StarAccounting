# 网页版登录后二次 API 检测层闪现修复

## 问题

网页版已有登录态或刚完成登录后进入账本时，根入口会短暂显示“正在检测云端服务...”及 API 地址检测控件，看起来像又弹出了一层登录检测页面。

## 原因

- 根入口启动云端连接检查时，立即把页面阶段从 `BOOTING` 切到可见的 `AUTH`。
- API 检测控件没有按验证状态收起，连接成功后仍与登录内容一起渲染。
- 已有的修复只隐藏了“正在进入账本”和“正在准备账本”占位，没有覆盖这条自动恢复会话路径。

## 实施步骤

1. 自动恢复会话时保持 `BOOTING`，连接成功且已有账户后直接进入账本。
2. 没有登录态或连接失败时再进入 `AUTH`，保证登录和错误处理仍可用。
3. API 验证通过后收起检测控件，只显示账户登录或已登录操作。
4. 检查改动范围和开发服务编译状态，记录用户可见修复并提交到本地仓库。

## 完成标准

- 网页版已有登录态进入账本时不再闪现 API 检测层。
- 登录成功后的路由切换不再显示第二层检测卡片。
- 首次登录、修改 API 地址、连接失败和手动重新检测仍可正常显示对应控件。

## 完成记录

- 自动连接和会话恢复期间保持入口隐藏，已有账户验证成功后直接进入账本。
- API 验证完成后收起地址、状态和检测按钮，只保留登录或账户操作。
- 连接失败、修改地址和手动检测仍会显示 API 检测控件。
- 当前开发服务已完成热更新编译，变更通过差异与格式检查。

修复 / PATCH：恢复已有登录流程的预期表现，不增加新任务，也不改变账户或账本数据。
