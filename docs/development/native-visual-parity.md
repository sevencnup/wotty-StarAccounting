# 纯 Kotlin 版视觉一致性开发记录

## 目标

缩小纯 Kotlin/Compose 版与网页版在字号、字重、卡片层级、间距和模块布局上的差距。网页版已经迭代到新的首页组件，而原生首页仍保留一套独立的 `WebReplica*` 实现；本轮先修复所有原生页面共享的阅读体验，再对齐首页核心卡片，并通过手机截图检查是否出现截断或拥挤。

## 已确认的差异

- 网页默认正文基准为 15px，原生版有大量直接写死的 8–13sp 小字号。
- 原生主题把默认字重设为 Normal，且使用固定 Normal 的 sans-serif 字体对象。
- 网页首页使用 `StarkCrystalHero` 和 `StarkBudgetAllocationCard`；原生首页仍使用 `WebReplicaHero` 和 `WebReplicaBudgetCard`，布局和视觉层级已经分叉。
- 网页卡片按模块使用不同圆角：新版预算卡片约 18px、余额卡片 20px、罗盘小卡 16px；原生这些圆角基本接近，但默认内边距偏紧、卡片阴影偏弱，首页模块间距也小于网页。
- 储蓄页的 `Scaffold` 已经应用系统状态栏内边距，页面标题又重复应用一次，导致标题和首个模块整体下沉。

## 本轮执行步骤

1. 建立清晰的原生字号层级和更合适的标准字重，保留用户的系统字号偏好，并避免把大号金额和图表水印不必要地放大。
2. 保留网页按模块设定的圆角层级，对齐共享卡片内边距、背景、边框、轻阴影及首页模块间距，并移除储蓄页重复的状态栏留白。
3. 优先调整首页标题、核心余额卡片与资金分配卡片，使其采用与网页新版一致的空间层级；保留原生数据和交互逻辑。
4. 构建调试版并在手机上检查首页实际排版、文字可读性和裁切情况；按截图结果修正。
5. 更新原生版版本记录和开发版本号，提交本地仓库，不推送 GitHub。

## 后续页面顺序

本轮首页样式确认后，按网页版页面顺序继续对照消费、储蓄、贷款、资产、设置，逐页迁移共享设计规则并检查各自的数据模块与交互。每轮以实际手机页面检查为准，不只凭代码推测。

## 储蓄页对照执行

网页版储蓄页的顺序是规划提醒、储蓄总览、三项指标、目标组、最近计划。原生页目前把“新建目标”和本月计划单独做成大卡片，目标组与计划行也比网页占用更多纵向空间，导致首屏信息层级和网页版差异明显。

本轮按以下步骤调整：

1. 使用网页版相同的储蓄总览层级，展示累计存入、总目标、剩余金额、总进度和目标数量。
2. 将本月计划、目标缺口、计划完成率收拢为一组三项指标卡，并对齐网页的目标组区域；在目标组标题旁放置新建入口。
3. 将目标卡和按年份归组的月度计划改为更紧凑的原生卡片，保留编辑目标、实际存入、修改记录和凭证预览交互。
4. 构建调试版，安装到手机查看储蓄页首屏与滚动区域，根据实际截图修正间距、字重和拥挤问题。
5. 以体验优化 / PATCH 递增原生调试版本，更新版本记录并提交本地仓库，不推送 GitHub。

体验优化 / PATCH：本轮对齐原生储蓄页的模块层级、总览卡、指标、目标组与计划列表，未增加新的用户任务能力。调试包由 `0.21.0-dev.6` 迭代至 `0.21.0-dev.8`，Android `versionCode` 递增至 `10040`。

## 贷款页对照执行

网页版贷款页由规划提醒、还款总览和环形进度、三项月供指标、月供趋势、负债构成、还款日程及贷款组合组成。原生版已具备相同的数据模块，但提示卡配色、云端提示占高、压力指标主次顺序及多个细项字号仍与网页不同；空数据时趋势图也需要检查显示效果。

本轮按以下步骤调整：

1. 对齐规划提醒和还款总览的颜色、层级、文案与间距，保留原生新增贷款入口。
2. 缩短未连接提示占用空间，并按网页顺序和含义呈现月供、还款压力、下期到期三项指标。
3. 提高趋势图、负债构成、还款日程和贷款卡片正文的可读性，保持原生已有还款登记、编辑、删除操作。
4. 在手机上检查空数据及滚动布局，确认底部导航可用；构建、安装新调试版并停止临时进程。
5. 以体验优化 / PATCH 递增原生调试版本并提交本地仓库，不推送 GitHub。

贷款页体验优化 / PATCH：按网页版梳理提醒、还款总览、月供指标、趋势图、负债构成和还款列表，保留原生已有操作。储蓄页迭代后继续使用同一 `0.21.0` 调试目标，最终版本号为 `0.21.0-dev.10`，Android `versionCode` 为 `10042`。

## 资产页对照执行

网页版资产页依次展示规划提醒、净资产与资产/负债总额、对比进度条、三项指标、资产配置环图与明细、资产和负债账户清单。原生页目前额外显示一个环形总占比、云端状态单独占行，配置图例与账户分布挤在横向窄列里；资产与负债分组也没有网页的独立分区背景，部分账户文字仍偏小。

本轮按以下步骤调整：

1. 将提醒改为与其他财务页一致的暖色提示，压缩本地/云端状态提示，并保留新增资产入口。
2. 按网页结构展示净资产估值、资产与负债金额、对比条和关键指标，移除重复表达资产占比的装饰性环图。
3. 将手机上的配置环图放在分布明细上方，并把正向资产和应还负债整理为有独立底色的分组。
4. 提高指标与账户行的字号，并让零余额资产仍能出现在资产明细中。
5. 构建、安装到手机检查首屏和滚动列表，停止临时进程；以体验优化 / PATCH 递增版本并提交本地仓库，不推送 GitHub。

资产页体验优化 / PATCH：对齐净资产总览、指标、配置分布和资产/负债明细，修正零余额资产未显示的问题。版本递增至 `0.21.0-dev.11`，Android `versionCode` 为 `10043`。
