# 订阅选择器、录入页操作区与结余修复

## 需求与分类

修复订阅/扣费管理中的消费分类和支付平台选择弹层被父弹层遮挡的问题；让记账、储蓄计划和资产录入的保存操作在长表单滚动时始终可见；核对自动扣费流水与结余的同一笔记账关系。三项都是已有功能未按预期工作或操作不便，归类为修复/体验优化（PATCH）。

## 实施步骤

1. 让 ChoicePicker 的弹层高于设置页弹层，并保留原有返回、遮罩和关闭行为。
2. 调整 JournalPanel 内的保存操作区，使记账、储蓄计划、资产及同容器内的其他录入操作可在底部固定显示，内容仍可滚动到最后一项。
3. 沿自动订阅流水、消费统计、首页结余与预算余额的数据流定位差异；修复对应计算或刷新链路，避免一笔扣费重复计算。
4. 审阅改动并本地提交；安装包构建留待单独的发布任务。

## 验收范围

- 两个选择弹层能在订阅/扣费管理上方完整显示并操作。
- 长表单滚动时保存按钮始终可见，不遮挡最后一项输入。
- 已生成的订阅支出在对应结余口径中只扣减一次。
