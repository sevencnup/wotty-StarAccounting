# 记住首页顶部指标卡片选择

## 问题与目标

首页顶部指标卡片在组件卸载后会恢复到默认的“支出”。切换底部页面再回到首页时，用户之前选中的“结余”或“收入”没有保留。将该选择保存在本机配置中，后续进入首页时恢复上次选项。

## 实施步骤

1. 在本地配置存储中增加首页指标卡片的读取和保存方法，并校验只接受有效选项。
2. 首页首次载入时恢复已保存选项；用户切换指标时立即更新界面并保存。
3. 静态检查默认值、读取回退及类型；不增加或运行测试。
4. 更新版本记录，只提交本次文件到本地 Git，不推送 GitHub。

## 验收重点

- 首次使用仍默认显示“支出”。
- 切换到“结余”或“收入”后，离开再回到首页时仍显示上次选择。
- 无效或缺失的本地值安全回退到“支出”。
