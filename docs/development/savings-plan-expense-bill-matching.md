# 首页储蓄计划支出账单匹配

## 目标

首页“储蓄计划安排”的固定/临时支出明细目前只展示计划值，用户无法快速确认对应消费是否已记账。用计划支出名称作为关键词，在对应薪资周期或自然年账单中寻找消费，并为找到的项目显示绿色“已记账”状态。

## 实施步骤

1. 复用账单关键词搜索字段和归一化方式，按计划支出名称匹配消费；只匹配支出和已归类为支出的流水。
2. 月度首页按当前计划对应的完整薪资周期查找，年度视图按所选自然年查找。
3. 汇总每项支出命中的所有账单金额，并与计划金额按分比较；金额相符显示绿色勾选，未达或超出时显示已记金额和差异状态。
4. 保留原计划金额不变；没有匹配时维持原样式。
5. 检查数据流、周期边界及类型，不新增或运行测试。
6. 作为新增能力更新 MINOR 版本和迭代记录，只提交本地 Git。

## 验收重点

- 多笔分次消费按计划名称归并求和；合计与计划金额一致时显示绿色勾选。
- 合计未达或超出计划金额时显示实际合计和对应状态。
- 收入、未归类转账、其他周期内的流水不能触发标记。
- 年度视图只使用所选年份的账单。
- 标记不修改计划金额、账单或储蓄数据。
