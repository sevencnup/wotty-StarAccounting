# 星会计 0.8.0 公测发布准备

## 目标

- 将应用内下载安装更新功能从 `0.8.0-dev.1` 推进为首个 `0.8.0` 公测包。
- 让手机上已安装的 `versionCode 164` 开发版能通过更新接口检测并安装公测包。

## 发布约束

- 公测版使用 `0.8.0-beta.1`，Android `versionCode` 递增为 `165`。
- GitHub Actions 由 `v0.8.0-beta.1` 标签触发，构建 KT 混合版并用现有签名密钥发布 APK。
- 手机暂时保留 `versionCode 164`，以便发布后验证应用内升级；此阶段不直接覆盖安装 `165`。
- 仓库规范要求：先本地提交，只有收到明确的推送命令才推送 GitHub。发布前不得推送标签。

## 步骤

1. 同步 `app/package.json`、Android Gradle 和前端当前版本常量，并记录公测版更新描述。
2. 完成本地公测包构建准备，保留既有安装包，不覆盖旧包。
3. 本地提交并创建 `v0.8.0-beta.1` 标签。
4. 收到明确推送命令后推送发布标签，由 GitHub Actions 构建并发布公测包。
5. 确认 `https://s.wotty.app/version.json` 返回 `versionCode: 165`、`edition: ktweb` 和新 APK 地址；再用手机上的 `164` 测试应用内更新。
