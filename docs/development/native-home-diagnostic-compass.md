# 纯 Kotlin 首页财务诊断与四维罗盘

## 目标

按 Web 首页 `buildHomeSummary` 的数据口径补齐纯 Kotlin 首页的财务诊断与四维罗盘。诊断条、诊断详情和罗盘共享同一份汇总，避免卡片提示与详情数据互相矛盾。

## 已核对的 Web 规则

- 首页摘要入口：`app/src/lib/stark/dashboard/summary.ts`。
- 预算支出范围：`app/src/lib/stark/dashboard/budget-period.ts`。年度预算按选中年份汇总；月度预算跟随所选月，年度报表下按 Web 逻辑汇总所选年。
- 预算提醒最多展示三项，按使用比例从高到低排序；达到提醒线为关注，达到 100% 为超支。
- 诊断明细最多三条，包含最大支出分类、与上期支出对比、预算提醒和大额支出；大额支出排在最前。
- 详情现金流结余扣除支出、还款和完成的实际储蓄；月份/年份切换分别对比上月/上年。
- 四维罗盘预算余量使用最高优先级预算提醒；待还贷款显示最近还款剩余天数；储蓄达成使用所有储蓄目标及完成计划记录的 Web 汇总口径。

## 当前原生差异

- 诊断条通过“支出大于收入”和一个全局预算比例自行判断，没有使用诊断明细。
- 诊断详情只显示收入、支出、净变动，没有显示诊断明细或预算进度。
- 罗盘预算余量直接用支出除以单个月预算/收入，贷款卡显示剩余本金，储蓄卡只汇总进行中的目标。

## 实施步骤

1. 新增可复用的原生首页摘要计算，统一计算周期现金流、预算提醒、诊断明细、储蓄达成比例与最近还款日。
2. 诊断条和详情改用摘要结果；详情显示 Web 同款现金流、诊断明细及预算进度。
3. 罗盘预算、贷款与储蓄卡改用同一摘要结果，保留原生页面跳转。
4. 递增纯 Kotlin 版开发版本并更新版本记录和完整开发清单。
5. 构建独立 `.dev` 调试包。手机当前停留在 Codex Remote 时不触屏、不强行切换前台；待设备处于可安全验收状态后再完成安装和界面核对。

## 验收范围

- 月份与年份切换时，收入、支出、现金流结余和上期比较范围正确。
- 月度/年度预算按 Web 规则排序、限制三项并显示提醒等级与进度。
- 诊断条与详情引用同一首条诊断和风险状态。
- 大额支出、分类占比、上期支出变化及预算提醒均能进入详情。
- 罗盘预算余量、贷款最近到期天数、储蓄计划完成比例与诊断摘要一致；无预算/无贷款/无储蓄时显示合理空态。
- 保留预算管理、资产、贷款和储蓄卡的原有点击跳转。

## 版本分类

新增诊断明细与预算进度展示，并扩充罗盘数据口径，属于新增功能 / MINOR。目标版本为 `0.19.0-dev.1`，Android `versionCode` 为 `10031`。
