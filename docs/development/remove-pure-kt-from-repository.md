# 从 GitHub 主分支移除纯 KT 版

## 目标

从仓库当前版本移除独立的 Kotlin + Jetpack Compose 纯 KT 安装版，只保留 Web 壳版和 KT 混合版。使用常规提交更新 `master`，不改写 Git 历史；此前的提交仍可在 GitHub 提交历史中查看。

## 实施步骤

1. 删除纯 KT Android 模块。
2. 删除仅供根目录原生工程使用的 Gradle wrapper、配置和模块引用。
3. 更新 README、Android 版本说明和原生版完整开发计划的状态，确保当前构建说明只列出两个版本。
4. 将主应用版本从 `0.5.1-dev.2` 提升到 `0.6.0-dev.1`，Android `versionCode` 从 `152` 提升到 `153`，记录移除的安装版。
5. 检查改动范围，只提交本任务涉及的源码与文档；完成本地提交后推送到 GitHub `master`。

## 分类与版本

这是安装版本能力移除，属于不兼容变更；当前仍处于 `0.x` 阶段，目标版本为 `0.6.0-dev.1`。Web 壳版和 KT 混合版保留。

## 验收

- 当前仓库不再包含纯 KT 模块或对应的构建入口。
- Web 壳版和 KT 混合版构建配置仍保留。
- README 和 Android 版本说明只介绍当前保留的两个版本。
- GitHub 使用普通前向提交更新，不强推、不改写既有提交历史。
