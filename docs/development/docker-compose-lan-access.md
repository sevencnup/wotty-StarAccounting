# Docker Compose 局域网访问

## 目标

让本机常驻部署的 Web 页面可通过 `192.168.15.22:12366` 和 `10.126.126.3:12366` 访问，同时继续使用同机 `12367` 端口的云端 API。保留现有账本和密钥卷，MySQL 端口继续只绑定本机回环地址。

## 实施步骤

1. 为 Compose 的 Web 端口增加可配置的宿主机绑定地址，默认保持 `127.0.0.1`；需要局域网访问的部署可设置为 `0.0.0.0`。
2. 在 `.env.example`、README 和数据库部署说明中写明设置方法、两个本机网络地址、API 地址及数据卷保护方式。
3. 提交源码到本地 Git，并将变更同步到此前指定的 Gitea `main`；不推送 GitHub。
4. 在本机常驻部署目录拉取 Gitea 更新，只在该目录的 `.env` 设置 Web 绑定地址，重新创建受影响的容器，不删除数据卷。
5. 检查 Web 可通过两个本机网络地址打开，API 健康接口返回 `db:true`，跨域响应正确，MySQL 仍只监听 `127.0.0.1:3307`。

## 分类与版本

现有 Compose 部署只能从本机打开 Web；新增局域网访问能力属于新增功能（MINOR）。根工作区目标版本为 `0.2.0-dev.1`；Android 安装包不变。
