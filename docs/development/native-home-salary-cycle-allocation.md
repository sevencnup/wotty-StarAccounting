# 纯 Kotlin 首页薪资周期资金分配

## 目标

对照 Web 首页 `app/src/app/app/(tabs)/page.tsx` 和 `app/src/lib/stark/dashboard/salary-cycle.ts`，让原生资金分配卡按薪资周期统计；全年视图按自然年统计。保留已设置的月度/年度预算用于提醒诊断，不把预算上限当作本期收入。首页结余、支出/收入指标和“自然月/发薪周期”选择也要按 Web 持久化，切页或重启后保留。

## Web 口径与原生差异

- Web `buildHomeSummary` 的月度资金分配使用 `forecast.cycleIncome/cycleExpense/cycleRepayment/cycleSavings`；`forecast` 根据选中的统计月、发薪日和当前日期计算发薪周期。年度统计使用所选自然年的收支和存款。
- 薪资周期开始于所选月份的发薪日、结束于下月同日之前。查看当前月份且当前日还未到发薪日时，周期从上月发薪日开始。转账不改变账本净额；还款计入扣减；储蓄使用该周期内已完成计划的实际存入金额和日期。
- Web 预算卡的可安排金额是周期收入减去实际消费、还款和已完成储蓄，不含上期结转。预算实体用于预算提醒与诊断，不改变这一计算。
- Web 将首页指标和“自然月/发薪周期”选择保存到本地偏好。原生 `HomeScreen` 把指标及周期状态保存在 Composable `remember` 中，离开页面或进程重建会恢复默认值。
- 原生预算卡使用自然月流水，并在存在预算时拿预算金额作为分配基数；这会让发薪日后的实际收入/支出范围与 Web 不一致，也会将预算上限误作收入。

## 实施步骤

1. 新增可核对的薪资周期区间和周期收支汇总，按 Web 的当前月发薪日前滚动规则计算；支持自然年范围。
2. 月度资金分配汇总周期内真实收入、消费、还款及已完成储蓄计划的实际存入；不计转账、不计上期结余。全年视图汇总所选自然年的对应数据。
3. 调整首页资金分配卡的标题、薪资周期日期说明、可支配金额及进度比例；预算配置不再改变收入或可支配金额。自然月和年度预算提醒仍保持原统计范围。
4. 把首页主指标与结余统计周期选项保存到本地偏好，并在重新进入首页及强制停止后恢复。
5. 增加薪资周期范围的英文显示文案；更新完整开发清单及 `CHANGELOG.md`。这是已有口径的修正和偏好持久化，按 PATCH 递增到 `0.16.0-dev.2`，Android `versionCode` 递增到 `10026`。
6. 构建并安装独立调试副本。在真机核对 2026 年 10 月工资日范围、月度和年度汇总、切换首页指标/周期后的切页及重启恢复，并确认预算金额只影响提醒、不改变资金分配。使用已有账单进行只读验收，不修改测试流水。
7. 执行 `git diff --check`，更新验收结果，只提交源码、版本和开发文档到本地 Git，不推送 GitHub。
