# 订阅自动扣费

## 目标

在设置页维护按月固定扣费的订阅，应用启动或从后台恢复时自动补记到期月份的消费流水，避免用户手工重复记账。订阅配置和自动生成的流水同时支持本地模式与云端模式。

## 规则

1. 每条订阅包含名称、每月扣费日、金额、消费分类、支付平台、支付方式、开始日期和启用状态。
2. 扣费日按月执行；当月份没有该日期时，使用当月最后一天。
3. 应用启动、页面恢复和设置页打开时，补记开始日期到当前日期之间所有应产生的月份。
4. 每个订阅每个月使用确定性流水 ID 和订单号，重复打开应用不会重复记账。
5. 自动生成的流水类型为支出，分类默认“会员订阅”，商户为订阅名称，并保留“订阅自动扣费”描述。
6. 删除或停用订阅不会删除历史已生成流水；停用后不再产生新流水。

## 实施步骤

1. 增加订阅模型、本地 IndexedDB 存储和本地/云端仓库接口。
2. 增加云端 subscription 表、同步权限、查询和写入支持，并让数据库自动迁移创建缺失表。
3. 增加按月补记算法及幂等测试，接入应用启动和后台恢复。
4. 在设置页增加订阅管理入口、编辑表单、启停和删除操作。
5. 更新版本记录，执行类型检查、相关测试和生产构建。

## 验收标准

- 可以新增、编辑、停用、删除订阅，并显示扣费日与金额。
- 启用订阅在到期月份生成一条消费；重复触发同步不增加重复流水。
- 31 日订阅在二月等短月份按最后一天入账。
- 本地和云端模式的订阅配置都能保存并生成对应流水。
