# 首页资金分配展示储蓄计划支出

## 现状与目标

首页“本月资金分配”只按已入账收入、消费、还款与已完成储蓄计算。储蓄计划表中的固定、临时支出和预计存款属于规划金额，目前没有在首页展示。让用户在同一张卡里看到实际分配和储蓄页计划安排，并明确两组金额的口径。

## 数据规则

- 实际可安排金额继续使用真实流水和已完成的储蓄存入，不把计划金额再次扣入实际现金流。
- 读取所选月或年的已保存储蓄计划，匹配当前目标配置的存储频率；旧计划缺少频率标记时保留兼容。
- 解析计划行的支出列，按目标配置区分固定和临时支出；“上月结余”只作为计划结转，不算支出。空值、无效值和负值不产生计划支出。
- 计划区展示固定支出、临时支出、预计存款及各支出项目。仅在所选月份只有一份计划时展示该计划表的预计剩余；多份计划和年度视图不合并计划薪资或上月结余来推断可用现金。
- 计划区和实际区使用不同标题及说明；没有对应计划时不显示计划区。

## 实施步骤

1. 在独立的汇总函数中按所选报表期间整理储蓄计划支出及存款，复用现有计划数据解析规则。
2. 在首页资金分配卡增加计划区和支出明细，保持实际区的计算口径。
3. 补齐中英文文案与移动端样式，确保多项目可滚动查看。
4. 静态核对计划解析、月份/年度筛选、频率、上月结余和重复扣除风险；测试与构建留待明确要求时执行。
5. 按用户可见变化评估版本类别，记录更新描述并提交本地仓库。

## 验收重点

- 保存储蓄计划中的固定、临时支出后，首页所选期间显示对应金额和项目名称。
- 已完成存款的实际金额与已记账消费只参与实际区；计划区保留原计划数值，实际可安排金额不会被重复扣减。
- 旧数据缺失或支出 JSON 异常时，首页仍正常显示。
