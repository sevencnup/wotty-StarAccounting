# 首页储蓄计划折叠与储蓄达成进度修复

## 现状与目标

- 首页“本月资金分配”里的储蓄计划明细默认全部展开，导致卡片过高。改为默认收起，保留标题、预计存款概览和储蓄页入口；用户可展开查看原有明细。
- 首页“储蓄达成”只按目标的 `currentAmount / targetAmount` 计算；储蓄总览会兼容已完成计划的实际存入金额，并在目标金额未填时使用计划总额。因此两页可能显示不同进度，首页甚至一直为 0%。统一计算口径。

## 实施步骤

1. 提取共享的储蓄进度汇总，复用储蓄总览现有的已存金额和目标金额规则；首页与储蓄总览使用同一结果。已跳过和待存入计划不计作已存金额。
2. 给首页储蓄计划区增加默认收起的切换按钮。收起时展示预计存款概览；展开时保留工资来源、计划金额、支出明细和预计可支配金额。储蓄页链接始终可用，按钮与链接分别响应。
3. 补齐中文和英文提示以及窄屏样式，保持键盘可操作与展开状态提示。
4. 静态检查改动和版本文件；本次不增加或运行测试。按修复及体验优化递增小版本，记录更新描述并仅提交本地仓库。

## 验收重点

- 首次进入首页时计划明细收起，点按切换按钮可展开和再次收起；点击储蓄页链接正常跳转。
- 首页“储蓄达成”与储蓄页“总进度”一致；只有计划、尚未实际存入时仍显示 0%，已完成且有实际存入时按已存金额计算。
- 目标金额为 0、多个目标、旧计划未保存实际金额以及无储蓄数据时结果稳定。
