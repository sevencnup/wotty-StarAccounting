# 全部底部滑出页覆盖底栏

## 需求与分类

用户要求底部滑出的页面在打开期间覆盖应用底部导航栏。上一轮只处理了记账页面模式；本轮统一处理共享 `BottomSheet` 与所有 `JournalPanel` 模式，包括 Web 壳和 KT 混合版。此项修正已有弹层的覆盖范围，分类为体验优化 / PATCH。

## 实施步骤

1. 将共享底部弹层和记账弹层的遮罩延伸到视口底部，重新计算面板高度，并保留系统底部安全区内边距。
2. KT 混合版只要检测到任一底部弹层挂载就隐藏原生底栏；弹层卸载后恢复，关闭动画期间继续遮住底栏。
3. 更新应用版本与用户可见版本记录，构建独立命名的 Web 壳和 KT 混合版 APK，安装到已连接手机并核对版本。
4. 完成本地提交，不推送远端。

## 验收

- 任意共享底部弹层或记账弹层打开时覆盖应用底栏；关闭后底栏恢复。
- 面板底部操作区域仍能滚动到并点击，系统手势安全区不被内容压住。
- Web 壳和 KT 混合版安装版本一致，历史 APK 保留。

## 实施结果

- 共享 `BottomSheet` 和全部 `JournalPanel` 模式的遮罩延伸到应用底部；面板高度不再为应用底栏预留空间，底部仍保留系统安全区内边距。
- KT 混合版在两类弹层挂载期间隐藏原生底栏，关闭动画完成后恢复。
- Web 壳和 KT 混合版已构建并安装到 `10.126.126.2`，设备报告 `0.5.0-dev.4`、`versionCode 146`。
