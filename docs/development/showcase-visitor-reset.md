# 演示访客改动刷新还原

## 目标

手机模型和独立 Web 演示是一次性的试玩账本：访客在当前页面内的记账、储蓄、贷款、资产及设置操作立即生效，整页刷新或重新打开后恢复到由当天日历生成的同一套标准演示数据。正式 App 和云端账本保持原行为。

## 边界

- 只在 `NEXT_PUBLIC_SHOWCASE_DEMO=1` 下重置。站点首页的手机演示与独立 Web 演示使用不同的 IndexedDB 名称。
- 只在每次完整文档加载时重置一次；Next.js 页面内部导航不重置，React 开发模式重复挂载也不重置。
- 清空演示专用 IndexedDB 数据及演示专用本地/会话设置，然后重新播种固定样本和截至当天的月度事件。不能清空同源的普通 App 数据或宣传站数据。
- 现有演示访客此前保存在浏览器中的改动也会在首次打开新版演示时被还原；这是试玩模式预期行为。

## 开发步骤

1. 将演示 IndexedDB 按构建的 `APP_BASE_PATH` 分开，验证普通 App 库名不变。
2. 在演示路由授权、读库之前，原子清空演示专用存储区并清理演示专用浏览器键；保证单次文档加载仅执行一次。
3. 重新播种标准样本并补齐当月事件；确认内部路由切换保留当前试玩，刷新则恢复标准账本。
4. 增加隔离及重置测试，重建手机与 Web 演示，运行 App 测试、类型检查和网站构建。
5. 按修复/体验优化分类更新版本与简短记录，仅本地提交，不推送远程。
