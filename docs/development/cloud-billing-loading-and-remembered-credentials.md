# 云端账单加载与记住账密修复

## 目标

1. 避免云端认证、账本校正请求卡住后导致设置页或首页无限等待。
2. 避免重复进入页面时反复请求账本列表，减少云端模式的首屏等待。
3. 让登录页的“记住账密”保存邮箱和密码，并在下次打开时自动回填。
4. 避免 App 从后台恢复后，页面切换被全屏骨架状态永久遮住。

## 实施步骤

1. 为云端认证请求增加 AbortController 超时，并对账本校正请求做并发去重。
2. 修复云端数据请求提前清除超时定时器的问题，确保响应体卡住时也能结束请求。
3. 保留登录时的账本 ID 校正，同时避免受保护路由重复阻塞在账本列表请求上。
4. 增加本地凭据存储读写，登录成功后按勾选状态保存或清除，并在登录页初始化时回填。
5. 执行类型检查、前端测试和生产构建，确认登录与云端数据加载链路没有类型回归。
6. 移除会替换当前页面的导航骨架，路由未就绪时继续显示已有页面。

## 验收标准

- 云端 API 无响应时，页面在有限时间内显示错误，不会无限转圈。
- 正常云端模式可以进入设置页并加载首页账单。
- 勾选“记住账密”后重新打开登录页，邮箱和密码自动回填；取消勾选后不再保留。
- App 长时间后台恢复后，切换设置页不会无限显示骨架。
