# 原生记账表单草稿持久化

## Web 行为与原生差异

Web 的 `JournalPanel` 会将新增记账表单的类别、金额、平台、商户、日期和备注写入本地草稿；再次打开时恢复，成功保存后清除草稿。原生 `QuickEntrySheet` 使用 Compose 临时状态，关闭弹窗或进程重建后输入会丢失。

## 实施步骤

1. 在原生本地偏好中保存普通记账表单草稿，覆盖模式、收支类型、分类、金额、平台、商户、发生日期/时间及备注。
2. 草稿按当前数据范围和账本 ID 隔离，避免切换本地/云端账本或账号时串用。
3. 新建表单打开时恢复草稿，编辑已有流水时不加载或覆盖新增草稿。
4. 单笔记账或单月工资成功保存后清除草稿；批量工资补录保留表单输入，保存失败、关闭弹窗或应用重启也保留输入。
5. 更新版本记录至 `0.21.0-dev.3` / `versionCode 10035`。此项提升中断后的操作恢复能力，属于 PATCH。
6. 真机核对输入后关闭再打开、强制停止后重开、切换账本、保存成功清除和编辑流水隔离；过程中不要留下测试账单。

## 验收范围

- 未提交的表单字段可在重新打开及应用重启后恢复。
- 本地与云端账号各自读取自己的草稿。
- 编辑已有流水不改变未提交的新建草稿。
- 单笔记账或单月工资成功后重开表单显示干净初始状态；保存失败和批量补录后保留草稿。
- 仅保存偏好草稿，不在草稿阶段写入账本或云端。
