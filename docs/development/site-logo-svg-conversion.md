# 网站 Logo 转为 SVG

## 目标与分类

将星会计网站及交互演示使用的 640×640 Logo 从 WebP 改为 SVG，按用户指定在局域网 ImageTracerJS 页面转换，颜色数量设为 128、轮廓误差设为 0.1。

本次属于修复（PATCH）：更换现有 Logo 文件格式，不增加新功能。应用版本从 `0.7.5-dev.1` 增至 `0.7.6-dev.1`，Android `versionCode` 从 `159` 增至 `160`；宣传站版本从 `0.5.3` 增至 `0.5.4`。不构建 APK。

## 执行步骤

1. 使用 `http://192.168.15.22:8782/` 上传网站现有 Logo，设为 128 色与 0.1 轮廓误差并下载 SVG。
2. 将 SVG 用作 App favicon、宣传站标志与底部 Logo，替换现有 WebP 引用和文件。
3. 依次重建手机与 Web 静态演示，确认各自使用正确的 SVG 路径。
4. 检查 SVG 能被浏览器及构建工具解析，运行应用类型检查与宣传站生产构建。
5. 恢复 Next.js 自动修改的类型声明，仅本地提交本次应用与宣传站改动。

## 验收

- 转换来自指定局域网网页，SVG 保留原图的画布尺寸和透明背景。
- App、宣传站首页、指南页、页脚及两套交互演示均引用 SVG Logo。
- 修改的页面不再引用旧 WebP Logo；Android 原生安装图标不纳入本次替换。
- 手机与 Web 演示可从 LAN 地址访问；应用类型检查和宣传站生产构建通过。
