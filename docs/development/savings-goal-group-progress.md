# 储蓄目标组进度修复

## 问题与原因

储蓄页的目标组卡片需要兼容两类数据差异：一是目标保存金额与已完成计划记录不一致；二是目标的 `targetAmount` 为 0，但计划仍有金额。前一种情况会让已存金额不准确；后一种情况会让目标卡片显示“已存有金额、还差 0、进度 0%”。总进度已有按计划金额回退目标值的逻辑，目标组卡片也应按单个目标应用同样规则。

## 实施步骤

1. 增加按目标汇总已存金额的共享计算：对比目标当前已存金额与该目标的已完成计划实际存入金额，采用较大的值，不重复累加同一笔存入。
2. 单个目标的目标金额为 0 时，回退为该目标计划金额合计；总进度和目标组卡片统一使用相同规则显示进度和剩余金额。
3. 递增修复版本并更新迭代记录；不新增或运行测试。当前轮用户要求暂缓构建和安装，只做静态检查并提交本地仓库。

## 验收重点

- 已完成计划但目标金额未同步时，目标组进度按已完成计划金额显示。
- 目标本身没有设金额时，目标组用该目标各月计划金额计算总目标，不再出现“有已存、还差 0、进度 0%”。
- 目标金额已包含这些存入时，不会把计划金额重复加到已存总额。
- 不影响待存入、已跳过计划；目标金额已设置时优先使用该值，没有目标金额和计划时进度保持 0%。
