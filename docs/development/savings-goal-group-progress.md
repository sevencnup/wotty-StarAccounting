# 储蓄目标组进度修复

## 问题与原因

储蓄页的目标组卡片只读取 `SavingsGoal.currentAmount`；总进度和已完成计划则会兼容计算计划里的实际存入金额。目标金额与完成计划记录发生历史差异时，计划显示已完成，目标组进度仍可能显示为 0%。

## 实施步骤

1. 增加按目标汇总已存金额的共享计算：对比目标当前已存金额与该目标的已完成计划实际存入金额，采用较大的值，不重复累加同一笔存入。
2. 让储蓄总览汇总和目标组卡片复用该计算，并使用校准后的金额显示目标进度、已存金额和剩余金额。
3. 递增修复版本，更新迭代记录；不新增或运行测试。构建 Web 壳版与 KT 混合版，安装到已约定的手机，并提交本地仓库。

## 验收重点

- 已完成计划但目标金额未同步时，目标组进度按已完成计划金额显示。
- 目标金额已包含这些存入时，不会把计划金额重复加到已存总额。
- 不影响待存入、已跳过计划和目标金额为 0 的处理。
