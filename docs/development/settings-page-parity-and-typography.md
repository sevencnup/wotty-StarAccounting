# 设置页版本入口、箭头与弹层字体统一

## 需求与分类

开发网页版的设置页缺少“检查更新”，无附加文字的“帮助与反馈”箭头也没有与其他行贴齐；设置入口打开的弹层普遍使用更小、更细的文字。以上均为已有设置功能在不同运行环境中的显示差异和可读性问题，归类为修复/体验优化（PATCH）。

## 原因

1. “检查更新”被 Android 原生环境判断包住，浏览器环境不会渲染该行。
2. 设置行采用四列网格，但未指定箭头列；没有版本文字时，浏览器会把箭头自动放入第三列。发布分支曾有 `grid-column: 4` 修复，当前本地分支没有包含该提交。
3. 设置弹层沿用早期紧凑规格，说明、标签和按钮大量使用 8～11px 字号，与设置主页的 13px 主文字和 600 字重不一致。

## 实施步骤

1. Web 与 Android 都显示“检查更新”，浏览器点击后继续使用现有提示说明；Android 保留实际版本检查。
2. 明确设置行标题、版本值和箭头所在列，恢复新版本绿色提示点的状态联动。
3. 在设置弹层范围内统一主文字、说明、输入框和按钮的字号及字重，同时保留“关于”页应用名称等原有层级。
4. 审阅差异并本地提交；本次不构建安装包。

## 复核结果

- 两张截图分别显示开发版 `0.8.1-beta.1` 与混合版 `0.8.0-beta.1`，但当前本地分支没有包含发布线中固定箭头列和更新提示点的提交，因此版本名更新并不代表这些设置页改动仍在。
- 设置行现已明确使用第 1～4 列放置图标、标题、版本值和箭头；无版本文字的“帮助与反馈”也会与其他行右对齐。
- “检查更新”在 Web 与 Android 设置页统一显示；Android 后台检查发现新版本时恢复绿色提示点，Web 点击时继续给出浏览器版说明。
- 设置弹层标题、正文、说明、输入框和按钮使用统一的可读字号与字重，保留“关于”页面应用名称的原有视觉层级。
- 开发服务热更新编译完成，差异检查无空白错误。
