# 改善首页移动端文字与资金分配布局

## 背景与目标

当前 Android App 通过 Capacitor WebView 加载与浏览器共用的前端首页，旧 Kotlin Compose 首页已从主分支移除。截图中的资金分配卡片使用 10px 说明字、13px 标题和偏浅的次要文字，手机上显得细小；卡片内容层级也不够清楚。

本次聚焦首页移动端：提高核心信息的字号、字重和对比度，整理资金分配卡片的信息分组与间距。保持浏览器和 App 使用同一套页面和样式，不改动数据、入口和计算逻辑。

## 实施步骤

1. 检查首页关键卡片的基础样式和窄屏覆盖规则，确认修改在移动浏览器与 Android WebView 中共用。
2. 调整资金分配、财务诊断和首页指标卡的文字层级，提升说明文字的可读性与颜色对比。
3. 整理资金分配卡的分组、间距和窄屏布局，避免内容挤压或卡片过高。
4. 检查差异与 CSS 结构；不增加或运行测试。
5. 作为体验优化递增 PATCH 版本并更新简短记录，只提交本地 Git，不推送 GitHub。

## 验收重点

- 首页卡片标题、说明和金额的字号与字重层次清楚，说明文字在手机上易读。
- 资金分配卡的两组主要金额、分类构成、资产说明分组清晰，窄屏不溢出。
- 浏览器移动页面与 Android WebView 使用相同布局和样式。
