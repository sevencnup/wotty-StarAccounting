# 记住结余卡片的统计周期

## 问题与目标

首页顶部指标和结余卡片的周期选项是两层独立状态。上一项改动已记住“支出 / 收入 / 结余”，但结余中的“自然月 / 薪资周期”仍留在已卸载的卡片组件里，切页回来会恢复默认。将周期选项也保存到本机配置。

## 实施步骤

1. 为本地配置增加自然月和薪资周期选项的读取与保存，缺失或无效时回退为自然月。
2. 首页挂载时恢复已保存周期；切换时立即保存，并将受控状态传给结余卡片。
3. 更新 PATCH 版本和内部更新描述，静态检查切换与恢复路径；不增加或运行测试。
4. 递增 Android `versionCode`，生成独立归档包并安装到用户指定手机；只提交本地 Git，不推送 GitHub。

## 验收重点

- 首次使用默认自然月。
- 选择薪资周期后切换到其他页面再回来，周期仍为薪资周期；反向选择自然月也一样。
- 无效的本地配置安全回退到自然月。
