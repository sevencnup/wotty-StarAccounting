# 纯 Kotlin XLSX 账单导入

## 目标

缩小纯 KT 与 Web 账单导入的文件格式差异。Web 设置页接受微信、支付宝官方 CSV、XLS、XLSX 和本应用 CSV；纯 KT 当前只读取 UTF-8 CSV。本轮新增 XLSX 支持并改善 CSV 编码识别；Excel 文件仍走现有解析、预览、去重、确认、失败行记录和重试流程。旧式二进制 XLS 格式保留为明确提示的后续缺口。

## Web 与原生差异

- Web `app/src/lib/stark/import/bill-csv.ts` 使用 `xlsx` 读取 `.xls` / `.xlsx` 的第一个工作表，再用现有表头映射解析记录。
- 纯 KT `MainActivity.kt` 只接受 `.csv`，以 UTF-8 读取；选择 Excel 文件会直接报错。原生 CSV 未识别 UTF-8 时也缺少 Web 的 GB18030 回退。
- CSV 导入已有表头识别、行号和原始行、重复预览、确认导入及失败行重试。本次只扩展文件读取层，保持这些行为和 Web 的“只读取第一个工作表”规则。
- Web 与纯 KT 的历史失败列表都只显示导入错误记录；可以再次确认的失败交易保存在当前导入预览状态中。本次不改变此生命周期。

## 实施步骤

1. 使用 Android 自带 `ZipInputStream` 与 `XmlPullParser` 读取 OOXML `.xlsx`，解析工作簿关系并读取第一个工作表、共享字符串、行列地址、数值/文本/内联字符串及公式缓存值；不增加第三方依赖。
2. 将工作表行转换成原有字段解析器消费的记录格式。保留实际行号和空单元格；日期列识别 Excel 日期序列并转换为 `yyyy-MM-dd HH:mm:ss`。
3. CSV 优先按 UTF-8 / BOM 解码；出现替换字符时回退 GB18030，与 Web 保持一致。拒绝空文件、坏工作簿、无工作表和不支持的扩展名，并给出可读错误。
4. 文件选择器接受 `.csv` 和 `.xlsx`；旧式 `.xls` 明确提示先另存为 `.xlsx` 或 `.csv`。导入预览、重复检测、分类规则、贷款还款关联、部分失败记录和重试复用现有管线。
5. 更新设置帮助、英文文案、设置模块计划及完整 Kotlin 开发清单；这是新增可导入文件类型，按 MINOR 递增到 `0.18.0-dev.1`，Android `versionCode` 递增到 `10029`。修正行号和空工作表行处理时递增测试包序号至 `0.18.0-dev.2` / `versionCode 10030`。
6. 构建独立调试 APK。手机不在 Codex Remote 前台时，使用本地临时样例核对 CSV 编码、XLSX 首工作表、日期和金额字段、重复文件与导入后笔数；验证 `.xls` 提示，测试流水和文件必须清理。云端导入仅在已有隔离开发账本时验收。
7. 更新验收记录，执行 `git diff --check`，只提交本模块源码、版本和文档到本地 Git，不推送 GitHub，不纳入 APK 或构建目录。
