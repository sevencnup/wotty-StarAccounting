# 恢复支出结构图表的分类标签

## 问题与目标

首页“本月支出结构”的玫瑰图应直接显示扇区对应的分类标签。图表下方重复列出分类会让卡片过长，因此恢复图表外侧的分类名称和引导线，保留点击扇区查看金额和占比的交互。

## 实施步骤

1. 显示玫瑰图外侧的分类名称和引导线，并恢复合适的图表半径。
2. 移除图表下方重复的分类选择块及其样式。
3. 保留点击扇区查看数据、选择扇区的交互，并允许页面纵向滑动经过图表。
4. 检查图表 JSX 结构、空数据分支及差异格式；不增加或运行测试。
5. 只提交本地 Git，不推送 GitHub。

## 验收重点

- 扇区外侧显示对应的分类名称和引导线。
- 图表下方不再重复显示分类选择块。
- 点击扇区可查看金额和占比；纵向滑动仍可滚动页面。
