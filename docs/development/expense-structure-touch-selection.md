# 改善支出结构图表的触摸选择

## 问题与目标

首页“本月支出结构”的玫瑰图使用触摸提示，手指在上下滚动时经过图表会触发分类提示；金额较小的扇区又很难直接点中。减少图表对滚动手势的干扰，并提供尺寸足够的分类选择入口。

## 实施步骤

1. 将图表提示改成明确点击后出现，避免触摸移动时不断切换数据提示。
2. 在图表下显示与扇区对应的分类选择块，提供分类名、金额和占比，触摸区域至少 44px；点击选择块可定位对应扇区。
3. 保留图表直接点选作为补充操作；小扇区通过分类选择块也能选中。
4. 静态检查选择索引、合并分类及空数据分支；不增加或运行测试。
5. 更新 PATCH 版本和迭代记录，只提交本地 Git，不推送 GitHub。

## 验收重点

- 上下滑动经过图表不会触发分类选择或提示。
- 点击扇区或下方分类块都能选中对应分类。
- 很小的扇区可以通过大尺寸分类块选中，名称、金额和占比清晰可见。
