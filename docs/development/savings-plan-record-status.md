# 储蓄计划显示实际存入状态

## 问题与原因

储蓄页本月计划卡片固定显示“待执行额度”；首页资金预算下的“储蓄计划安排”汇总只统计计划金额，未读取计划状态及实际存入金额。因此记录存入后，这两处仍只展示预计金额，无法看出已完成和待存的情况。

## 实施步骤

1. 汇总当前月及首页计划周期内已完成、待存入、已跳过计划的金额与数量；已完成计划按实际存入金额统计，旧记录缺少实际金额时沿用计划金额。
2. 在储蓄页本月计划卡片中保留计划总额，并显示实际已存、待存金额及对应状态，移除固定的“待执行额度”说明。
3. 在首页“储蓄计划安排”折叠摘要和展开明细中显示已存与待存状态，同时保留原计划金额及原有预算计算口径。
4. 递增 PATCH 版本并更新版本记录；不新增或运行测试。构建 Web 壳版与 KT 混合版，安装到已约定手机，提交本地仓库。

## 验收重点

- 完成存入后，两处都显示实际已存金额及已完成状态。
- 同周期尚未完成的计划仍以待存金额显示；已跳过计划不误算为待存。
- 计划金额仍可见，且首页实际资金分配不重复扣减计划表金额。
