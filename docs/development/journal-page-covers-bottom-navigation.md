# 记账内页覆盖底部导航

## 需求与分类

全局“记账”按钮打开的内页需要延伸至应用底部，覆盖网页底栏和 KT 混合版原生底栏；关闭内页后恢复底栏。其他共用底部弹层仍使用原来的底栏避让布局。此项修正已有页面的覆盖范围，分类为体验优化 / PATCH。

## 实施步骤

1. 检查记账内页、键盘开启状态和 KT 混合版原生底栏的布局关系。
2. 仅让页面模式的记账面板延伸到视口底部，更新其高度限制与键盘可视区域计算，并保留底部安全区内边距。
3. 在 KT 混合版检测记账内页是否挂载；打开时隐藏原生底栏，关闭后恢复，其他路由和普通弹层保持原有行为。
4. 更新版本记录；构建带独立文件名的安装包，安装到已连接手机并核对版本；完成本地提交。

## 验收

- Web 壳版记账内页覆盖应用底栏，关闭后底栏恢复。
- KT 混合版记账内页打开时原生底栏隐藏，关闭后恢复。
- 记账面板底部操作仍可触达；其他底部弹层继续避让底栏。

## 实施结果

- 页面模式记账面板覆盖到视口底部，键盘打开时使用完整可视高度；底部安全区内边距继续保留。
- KT 混合版在记账内页存在期间隐藏原生底栏，内页卸载后恢复。
- Web 壳版与 KT 混合版已分别构建并安装到 `10.126.126.2`，设备报告版本 `0.5.0-dev.3`、`versionCode 145`。

后续已扩展为所有共用底部滑出页，见 [全部底部滑出页覆盖底栏](all-bottom-sheets-cover-navigation.md)。
