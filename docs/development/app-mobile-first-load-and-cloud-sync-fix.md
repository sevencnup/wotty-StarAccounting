# App 移动端首屏与云端数据修复

## 目标

1. 修复 Android App 输入框无法正常唤起系统输入法的问题。
2. 修复 App 首次打开底部滑出页面时的闪烁和初始定位异常。
3. 将退出云端账户提示改为白色卡片和蓝色操作按钮，统一移动端视觉。
4. 核查并修复 App 与开发模式使用同一云端账户却看不到账单的问题。
5. 修复登录/模式选择页面在不同窗口高度下偏移到顶部的问题。

## 实施步骤

1. 检查 Capacitor Android WebView 配置、输入框事件和移动端视口处理。
2. 检查 BottomSheet 首次挂载、动画初始状态及相关 CSS，避免首次绘制暴露过渡中间态。
3. 将原生 `window.confirm` 退出提示替换为应用内确认弹层，并统一白底蓝色按钮样式。
4. 对比 Web/App 的 API 地址、认证令牌、账户 ID 和云端账单请求参数，确认数据源一致性并补充必要修复。
5. 调整入口容器的垂直布局和键盘/视口变化监听，确保登录页面始终居中且输入时可滚动。
6. 执行类型检查、前端构建、测试和 Android APK 构建；安装新 APK 后逐项实测。

## 验收标准

- App 登录、注册、找回密码等输入框均可唤起输入法，键盘出现时表单可见且页面不抖动。
- 每个底部滑出页面首次打开与再次打开位置一致，不出现短暂闪烁。
- 退出提示为纯白 UI，操作按钮为蓝色，点击取消/确认行为正确。
- App 与开发模式登录同一账户后读取相同云端账单。
- 入口卡片在手机竖屏和桌面窗口中均保持合理居中。
