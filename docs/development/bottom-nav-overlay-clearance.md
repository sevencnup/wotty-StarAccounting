# 底部弹层避让导航栏开发记录

## 问题

记账面板和共用底部弹层延伸到视口最底部，遮住固定导航栏，也会让面板底部的保存等操作被导航栏压住。

## 实施步骤

1. 为网页导航栏和 KT 混合版 Kotlin 导航栏提供统一的底部安全距离；混合版使用原生导航栏实际高度。
2. 让全局记账面板及共用底部弹层的背景和触摸区域停在导航栏上沿，避免遮挡或拦截导航操作。
3. 将弹层最大高度限制在导航栏上方的可视区域，较长内容在弹层内部滚动。
4. 递增内部测试版本，构建并安装 Web 壳与 KT 混合版，核对导航栏和底部操作区。
5. 更新版本记录并本地提交，不推送 GitHub。

## 版本

体验修复，目标版本为 `0.4.0-dev.2`。Web 壳 Android `versionCode` 为 `138`，KT 混合版为 `139`；纯 KT 版不在本仓库构建。

## 验收

- 打开全局记账面板或其他共用底部弹层时，底栏仍可见、可点击。
- 面板底部的主要操作可在底栏上方显示并触达；内容超出可视高度时在面板内滚动。
- Web 壳和 KT 混合版可同时安装，更新各自应用时保留原应用数据。
