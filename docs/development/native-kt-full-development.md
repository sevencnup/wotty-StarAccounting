# 纯 Kotlin 原生版完整开发计划

## 目标

逐项审计星会计 Web 版的页面、交互和数据写入方式，再把可用功能按模块复刻到纯 Kotlin / Jetpack Compose 版。原生页面不得通过 WebView 套网页；继续使用独立包名 `com.wotty.stark.nativeapp`，与网页套壳版和 KT 混合版并存。

开发按可验收模块推进，每个模块完成后构建、装到 Android 真机核对，再开始下一块。用户已允许使用连接的手机进行调试。

## 已核对的数据契约

- Web 共用 `DataRepository`，包含流水、资产、预算、贷款、储蓄目标/计划、归类规则、周期扣费和导入错误记录的读取与写入。
- 云端 API 已提供对应实体的读取、保存和删除接口；流水另有批量导入和贷款还款归类接口。原生端应使用这些接口并检查响应结果。
- Web 本地模式使用 IndexedDB；云端模式带持久缓存。纯 KT 当前使用 `SharedPreferences` 保存简化流水 JSON 和少量首页偏好，且以直接 HTTP 调用读取云端摘要，尚无完整本地账本仓库。纯 KT 需要建立与 Web 实体字段相符的本地持久化，不得把云端缓存冒充独立本地账本。
- 流水需保留 `id/userId/accountId/amount/type/category/platform/merchant/date/description/orderId/paymentMethod/status/loanId/remarkCategory/createdAt/updatedAt`；储蓄计划需保留 `actualAmount/actualDate/expenses/remark/salary/proofImage/status/month` 等字段。
- Web 的进度和统计有领域逻辑，需复用或等价移植 `dashboard/summary.ts`、`savings/progress.ts`、`savings/planner.ts`、`ledger/balance.ts`、薪资周期与账单归类逻辑；不能只复制卡片外观。
