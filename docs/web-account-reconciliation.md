# 账户对账原型开发文档

## 目标

在设置页增加“账户对账”入口，先验证按支付账户对比账面余额与实际余额的交互。

## 本次范围

- [x] 从设置页进入账户对账底部面板。
- [x] 支持选择支付宝、微信、银行卡、现金等支付账户。
- [x] 支持按月填写月初余额和月末实际余额。
- [x] 根据当月流水计算账面余额与差异金额。
- [x] 支持将差异生成一笔“余额校正”流水。
- [x] 验证类型检查、生产构建，并完成本地 Git 提交。

## 计算规则

账面余额 = 月初余额 + 当月收入 - 当月支出 - 当月还款。

校正流水固定记录在对账月份的最后一天。

转账流水暂不计入账户余额，避免在只有单一支付账户字段时重复计算。

## 版本记录

本次为账户对账功能原型，不提升应用版本号。
