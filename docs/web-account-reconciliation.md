# 账户对账原型开发文档

## 目标

在设置页增加“账户对账”入口，先验证按支付账户对比账面余额与实际余额的交互。

## 本次范围

- [x] 从设置页进入账户对账底部面板。
- [x] 支持选择支付宝、微信、银行卡、现金等支付账户。
- [x] 支持选择月份后展示当月收入、支出、还款与账单结余。
- [x] 支持输入现有实际余额并计算与账单结余的差异。
- [x] 自动选择最近一个有账单数据的月份，并归并微信支付等平台别名。
- [x] 默认汇总全部支付账户的月度收支，也可按具体账户查看。
- [x] 支持将差异生成一笔“余额校正”流水。
- [x] 验证类型检查、生产构建，并完成本地 Git 提交。

## 计算规则

本月账单结余 = 当月收入 - 当月支出 - 当月还款。

差异 = 现有实际余额 - 本月账单结余。

校正流水固定记录在对账月份的最后一天。

转账流水暂不计入账户余额，避免在只有单一支付账户字段时重复计算。

## 版本记录

本次调整账户对账为按月展示收支并以现有实际余额校正，不提升应用版本号。
