# 本地数据库演示数据清理开发文档

## 目标

移除本地模式 IndexedDB 中的固定演示业务数据，并停止新安装应用自动生成演示数据，保留本地模式运行所需的默认用户与默认账本。

## 范围

- 清理固定 ID 的演示流水、资产、预算、贷款和历史储蓄演示记录。
- 不清空本地数据库，不删除用户导入账单、手动录入数据或草稿。
- 不修改云端 API 或云端数据库。

## 实施步骤

- [x] 梳理本地演示数据的固定 ID 与初始化入口。
- [x] 将演示 ID 集中定义并补充识别测试。
- [x] 初始化时清理固定演示记录及其关联储蓄计划。
- [x] 移除自动写入演示数据逻辑。
- [x] 运行测试、类型检查和生产构建。
- [x] 打包新 APK，通过 Wi-Fi 覆盖安装并验证演示记录已清理。
- [x] 更新版本记录并完成本地 Git 提交。

## 验收标准

1. 本地数据库不再自动创建任何演示流水、资产、预算或贷款。
2. 已安装旧版本的 App 升级后，固定演示记录被清理。
3. 用户导入或手动创建的数据不受影响。
4. 默认本地用户与默认账本仍可正常创建和使用。
