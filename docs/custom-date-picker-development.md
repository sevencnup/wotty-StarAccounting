# 自定义日期选择器开发文档

## 目标

- 用项目内的日期选择器替代 Android WebView 的原生 `date` 与 `datetime-local` 弹窗。
- 日期、日期时间字段使用同一套日历、年份/月切换、取消与确认交互。
- 保持现有数据格式、保存逻辑和表单校验不变。

## 实施步骤

1. 建立无第三方依赖的日期选择器组件与日期计算工具，支持日期和日期时间两种模式。
2. 实现自绘日历、月份切换、年份快速切换、时间选择、取消/清除/确认操作及键盘可访问性。
3. 替换记账、还款、储蓄记录、储蓄目标截止日期和账户余额基准中的原生日期输入。
4. 补齐移动端底部弹层样式和桌面端居中显示样式，保留 App 的安全区适配。
5. 为日期解析、闰年日历与输出格式添加单元测试；执行类型检查、全量测试和生产构建。
6. 更新版本记录并提交本地 Git 仓库，不推送 GitHub。

## 验收标准

- 点击任一日期字段不再出现 Android 原生日历弹窗。
- 日期字段输出 `YYYY-MM-DD`，日期时间字段输出 `YYYY-MM-DDTHH:mm`。
- 已有日期能正确回填；取消不修改原值，确认后才更新值。
- 2 月闰年、跨年切换、清除日期和小时/分钟选择均正确。
- 所有替换位置的业务保存逻辑保持可用。
