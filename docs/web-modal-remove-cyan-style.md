# 记账与各添加弹窗去除青色背景与边框开发文档

## 1. 需求与目标

去除记账、添加储蓄、添加贷款、添加资产、添加收入等所有弹窗页面中的青色/浅蓝背景与青色边框，统一替换为纯净的纯白/高级浅灰中性底色、细致灰边框与深色文字，消除视觉上的塑料感与青色色偏，与整站纯白极简 UI 风格保持绝对一致。

## 2. 影响范围

- `app/src/app/globals.css`
  - `.journal-panel` 弹窗底色（由 `#f5f8fe` 调整为 `#ffffff`）。
  - `.modern-amount-hero` 金额展示主区域（由青底 `#f0f9ff`、青边框 `#bae6fd` 调整为白底 `#ffffff`、灰边框 `#e2e8f0`，符号统一为深色文本）。
  - `.category-tile.active` 分类选中状态（由青底 `#e0f2fe`、青边框 `#7dd3fc` 调整为现代中性浅灰底 `#f1f5f9`、边框 `#cbd5e1`，深色文本）。
  - 各表单输入框聚焦高亮（去除青色高亮，转为平实质感的灰/纯蓝聚焦）。
  - 储蓄计划弹窗内的卡片与输入框边框（由 `#dbeafe` 调整为 `#e2e8f0`）。
