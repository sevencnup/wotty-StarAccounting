# 记账弹窗各模式（支出/收入/转账）顶部高度一致性修复开发文档

## 1. 需求与问题诊断

在记账弹窗（`JournalPanel`）中，用户在顶部切换“支出 / 收入 / 转账”三个模式时，发现“收入”和“转账”模式下弹窗顶部在屏幕中的高度与“支出”模式不一致。

### 根本原因分析：
1. **分类网格项数差异造成内容高度塌陷**：
   - “支出”模式拥有 15 个分类，5 列排列占 3 行，`.modern-category-matrix` 高度约 172px；
   - “收入”模式仅 4 个分类（1行），“转账”模式仅 1 个分类（1行），分类网格高度骤降为约 54px（塌陷约 118px）。
2. **底部抽屉面板高度自适应随内容变矮**：
   - 弹窗采用底部贴底抽屉布局（`align-items: flex-end`）。
   - 当从“支出”切换到“收入”或“转账”时，内容总高度减少 118px 导致贴底面板整体高度缩水，弹窗顶部（包含“记一笔”标题栏与分段选择器）在屏幕视口中瞬间下沉，产生剧烈的顶部高低跳动与位置不一致。

### 优化目标：
- 将 `.modern-category-matrix` 分类网格区域固定高度（`height: 172px` 或 `min-height: 172px`），确保“支出（3行）”、“收入（1行）”、“转账（1行）”时分类卡片区域占位完全恒定；
- 保持弹窗面板（`.journal-panel.page` / `.modern-journal-shell`）的统一高度规范，杜绝切换 tab 时弹窗顶部位置上下跳动；
- 确保在手机端与桌面端各种视口下，三个模式的顶部标题栏、分段切换栏在屏幕上的垂直坐标完全一致。
