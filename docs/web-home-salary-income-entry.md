# 首页工资入账快捷入口开发文档

## 目标

在首页收支总览中提供“工资入账”快捷入口，减少每月记录工资时切换页面和重复选择收入分类的操作。

## 交互设计

- 首页总览卡右下角增加“工资入账”操作，与现有明细入口并列。
- 点击后进入记账页，并预设交易类型为“收入”、分类为“工资”。
- 金额、收款账户、日期和备注保持由用户确认，避免自动入账或错误计入资产。

## 实施步骤

- [x] 在首页总览卡增加工资入账快捷入口。
- [x] 使用 Three.js 在同一坐标系绘制卡片右下缺口与蓝绿色工资入口，并保留 DOM 跳转文字层。
- [x] 验证跳转后的预设状态与保存逻辑。
- [x] 运行类型检查和生产构建。
- [x] 评估版本记录（本次属于小型视觉微调，不新增版本号），并完成本地 Git 提交。

## 验收标准

1. 首页可直接进入工资入账。
2. 打开的记账页默认选中“收入”和“工资”。
3. 用户仍可修改金额、账户、日期、分类后再保存。
4. 保存后仍作为普通收入流水参与首页统计。
