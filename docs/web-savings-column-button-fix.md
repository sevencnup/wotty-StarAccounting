# 储蓄计划新增支出按钮修复文档

## 问题

储蓄计划中的“新增固定支出”和“新增临时支出”按钮点击后没有明显反应。

## 原因

输入名称为空或名称重复时，新增列函数直接返回，没有给出界面反馈。

## 实施步骤

- [x] 确认按钮 DOM 和点击事件正常工作。
- [x] 为名称为空和名称重复增加提示。
- [x] 校验失败时自动聚焦支出名称输入框。
- [x] 运行测试和类型检查。
- [x] 更新版本记录并完成本地 Git 提交。

## 验收标准

1. 输入唯一名称后点击任一按钮，可以新增对应类型的支出列。
2. 未输入名称时点击按钮，会提示先输入支出名称并聚焦输入框。
3. 输入重复名称时点击按钮，会提示更换名称。
