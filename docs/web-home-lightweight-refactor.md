# Web 首页轻量化重构开发文档

## 1. 需求背景与目标
当前 Web 端首页（`web/src/app/(tabs)/page.tsx`）存在信息冗余与层级割裂问题：
- **双主视觉冲突**：收支卡片与独立净资产卡片并存，抢占注意力且首屏过长。
- **次级 Tab 内容全量平铺**：储蓄进度、贷款进度、预算提醒全堆在一个“杂货铺”式卡片中。
- **低频配置污染卡片**：发薪日配置直接在卡片内展开输入框，破坏纯粹性。

**优化目标**：
1. **一体化主看板 (Unified Hero)**：将月度结余、收支流向与轻量净资产胶囊整合为一个主视觉，支持自然月/薪资周期无缝切换，点击净资产胶囊可直达资产 Tab。
2. **情境化智能通知**：按需呈现异常或近期提醒（如预算预警、近期还款待办），无异常时折叠或展示轻量状态，移除冗余的常规进度条平铺。
3. **交互轻量化**：发薪日配置收敛为精致的轻量弹窗，不破坏主卡片流。
4. **近期记账精简**：首页保留最近 3 笔流水并提供快速直达入口，视觉紧凑明了。

## 3. 验收标准
1. 首页首屏高度显著降低，视觉焦点统一在当前周期结余与收支。
2. 净资产以胶囊形式嵌入主卡片，点击可无缝跳转到 `/assets`。
3. 发薪日设置以弹窗形式交互，配置即时持久化并刷新统计。
4. 提醒卡片仅在有待办/超支告警时高亮展示，无冗余进度条。
5. 整体视觉流畅且构建无报错。
