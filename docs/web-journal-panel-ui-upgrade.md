# Web 记账与新增面板现代化 UI 升级开发文档

## 1. 现状痛点与重构目标
原记账弹窗（`JournalPanel.tsx`）存在以下视觉与交互缺陷：
1. **金额输入过于简陋**：展示层与 input 分离，缺乏类似现代专业记账 App（MoneyWiz / 鲨鱼记账）的沉浸式**大字号居中金额看板**。
2. **分类与账户排版杂乱**：分类网格过于分散，缺少精致高亮的选中反馈。
3. **整体卡片缺乏层次**：各表单区块（金额、分类、账户、备注）平铺过于生硬。

**升级目标**：
- **沉浸式金额看板 (Amount Showcase)**：支持大粗体输入显示，自带清空按钮与动态人民币符号。
- **现代化精致分类网格 (Category Matrix)**：图标+文字胶囊，选中时带有柔和背景与品牌蓝高光。
- **轻量流式账户与时间备注栏**：紧凑胶囊切换，支持快速填充。
- **资产/贷款新增面板同步美化**：统一为精致的圆角现代表单与主操作按钮。
