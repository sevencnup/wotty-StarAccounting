# 储蓄计划记录与目标信息完善

## 目标

- 在储蓄首页目标卡片显示已填写的截止日期。
- 将月度节奏明确为全年计划执行概览，并允许从月份计划直接记录实际存入金额和图片凭证。
- 保留计划金额与实际存入金额的区别，更新目标已存金额时避免重复累计。
- 编辑储蓄目标时保留既有计划的实际存入金额和凭证图片。
- 兼容本地数据与远程 API 数据同步。

## 实施步骤

1. 扩展储蓄计划模型和数据库同步字段，增加实际存入金额。
2. 抽取储蓄计划记录业务逻辑并补充回归测试。
3. 在公共底部滑出面板中增加储蓄计划记录表单，支持实际金额、图片压缩预览、清除图片和保存。
4. 改造储蓄首页的月度节奏数据，使月份保留对应计划，并为计划提供记录或修改记录入口。
5. 在目标卡片补充截止日期，在月度节奏说明中解释其用途。
6. 执行类型检查、测试和构建，清理临时调试内容并提交本次相关修改。

## 验收标准

- 目标设置截止日期后，首页目标卡片显示该日期；未设置时显示未设置期限/No deadline。
- 月度节奏仍按月份汇总计划，但每个有计划的月份可以打开底部面板。
- 记录面板可以填写大于 0 的实际存入金额、选择图片并预览，保存后计划变为已完成。
- 计划金额不被实际存入金额覆盖，目标已存金额按实际金额增加。
- 修改已完成计划的实际金额时只计入差额，重复打开和保存不会重复累计。
- 编辑储蓄目标不会清除已有计划的实际金额和图片凭证。
- 本地模式和远程模式均能保存、读取新增字段。
