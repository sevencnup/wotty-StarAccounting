# 首页新增页面草稿实时保存开发文档

## 问题

首页的添加薪资收入、记账、添加储蓄、添加贷款、添加资产页面关闭后，已填写但尚未提交的数据会丢失。

## 目标

为五类新增页面增加本地实时草稿保存。页面关闭后重新打开时恢复草稿；成功提交后删除对应草稿，避免旧数据再次出现。

## 实施步骤

- [x] 梳理五类表单字段、打开入口和提交成功边界。
- [x] 增加统一的本地草稿存取工具。
- [x] 接入实时保存与重新打开恢复。
- [x] 在成功提交后清理对应草稿。
- [x] 增加草稿保存、恢复和清理测试。
- [x] 运行测试、类型检查和生产构建。
- [x] 更新版本记录并完成本地 Git 提交。

## 验收标准

1. 五类新增页面输入内容后，即时关闭，重新打开仍能恢复。
2. 成功提交后，对应草稿被删除。
3. 不同页面类型的草稿互不覆盖。
4. 现有正式数据保存逻辑不受影响。
