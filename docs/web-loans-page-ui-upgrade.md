# Web 贷款页 UI 升级方案

## 1. 目标
在保持贷款数据仓库、计算口径（本金、已还、月供、压力、日程排序）完全不变的前提下，升级贷款页面（LoansPage）的视觉层级、交互质感和信息呈现，统一到高质感的液态玻璃与数据可视化规范。

## 2. 优化要点
1. **还款指挥台 (Hero Console)**：
   - 增强渐变与玻璃质感，采用与暗夜/深青配合的深色玻璃态，提升高光和光晕层次。
   - 核心待还本金、已偿还金额强化排版层次，下一还款节点（倒计时天数、还款日、平台、金额）排版更紧致清晰。
   - 十段还款里程碑进度条改为连续带分段标记的平滑指示轨，提升视觉流动感。
   - 底部 3 项关键指标（月供、还款压力、剩余期数）增加带状态色彩指示的胶囊卡片。

2. **还款日程 (Schedule Timeline)**：
   - 时间轴序号与节点设计升级，临近还款（<=3天/今天）增加呼吸微光与醒目标识。
   - 优化每笔贷款的下期还款日、剩余期数、月供金额与剩余天数的左右对齐体验。

3. **贷款组合 (Portfolio Cards)**：
   - 贷款卡片提升质感（圆角、微渐变、毛玻璃边框），平台首字徽标增加平台专属色调或优雅渐变。
   - 状态标签（还款中、临近还款、已结清、已逾期）色彩与视觉统一。
   - 每项贷款的还款进度条强化为双色渐变与表面反光。
   - 增加已还/总额详细展示。

4. **响应式与无障碍**：
   - 移动端（<=430px）友好排版，杜绝文字挤压与溢出，进度条具备完整 `aria-label`。

## 3. 执行步骤
1. 修改 `web/src/app/(tabs)/loans/page.tsx` 优化结构与语义标签。
2. 修改 `web/src/app/globals.css` 完善贷款页面专属样式与移动端适配。
3. 执行 `pnpm --filter wotty-stark-web typecheck` 保证类型安全。
