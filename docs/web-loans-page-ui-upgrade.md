# Web 贷款页全维度 UI 升级方案

## 1. 目标
按照全站统一的明亮浅色液态玻璃（Light Glassmorphism）设计语言，将贷款页面（`LoansPage`）升级为一个兼具高信息密度、优雅数据可视化与实用还款管理的现代化财务控制台。

## 2. 详细升级模块
1. **还款指挥台 (Hero 仪表盘)**：
   - 顶部增加双环统计（总待还本金、月还款负担、总负债规模）。
   - 居中放置「下一节点倒计时微卡片」，清晰指引最近还款日、平台与金额。
   - 升级为动态渐变平滑进度轨与十段微光刻度，展示全贷款整体偿还进度。
   - 底部 3 项关键指标（本月月供、还款压力等级、总剩余期数）采用半透明玻璃胶囊卡片，支持自适应状态着色。

2. **还款分析与负债构成 (Debt Structure & Flow)**：
   - 增加按平台/类型的贷款构成分布条（房贷、车贷、网贷等各占比例），直观掌握负债构成。
   - 提供还款健康度与月供收入比评估提示。

3. **还款日程时间轴 (Repayment Timeline)**：
   - 优化时间轴序号节点，今天到期/3天内临近还款提供微光呼吸态与暖色状态标。
   - 强化单行信息排版（平台名称、到期日、剩余期数、月供金额、剩余天数徽章）。

4. **贷款组合卡片 (Compact Portfolio Matrix)**：
   - 紧凑型玻璃卡片设计，平台专属品牌首字徽标与状态芯片（还款中、临近还款、已结清、已逾期）。
   - 包含已还本金、待还本金、双色渐变进度条及月供金额。
   - 支持空状态优雅引导。

5. **响应式与无障碍**：
   - 移动端（<=430px）友好排版，杜绝文字挤压与溢出，进度条具备完整 `aria-label`。

## 3. 实施步骤
1. 修改 `web/src/app/(tabs)/loans/page.tsx` 补充负债结构分布与强化排版。
2. 修改 `web/src/app/globals.css` 编写配套的液态玻璃与图表样式。
3. 运行 `pnpm --filter wotty-stark-web build` 验证编译与类型安全。
4. 执行本地 git commit。
