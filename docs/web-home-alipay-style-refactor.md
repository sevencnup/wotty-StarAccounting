# Web 首页支付宝轻盈质感重构开发文档

## 1. 需求与设计参考
参考支付宝月度账单分析界面的轻量通透设计，彻底消除高饱和深蓝大卡片的视觉压抑感，提升首页美观度与信息传达效率。

### 核心改进点：
1. **轻盈通透微光 Hero**：
   - 采用浅冰蓝/青绿微光渐变背景，加入优雅的月份浅色背景印（如 `Aug`）。
   - 聚焦展示核心金额（结余 / 支出 / 收入自由切换），辅助展示记账笔数与统计口径。
2. **顶栏快捷控制器**：
   - 放置月份选择器与 `[ 结余 | 支出 | 收入 ]` 极简胶囊切换。
3. **自然语言月度小结 (Smart Summary)**：
   - 呈现智能财务洞察与健康度提示，替代生硬的百分比。
4. **4 格微型指标枢纽 (Quick Metrics Grid)**：
   - 净资产、预算消耗、待还贷款、储蓄进度 4 格等宽微卡，可点击直达对应 Tab。
5. **月度支出对比趋势 (Monthly Trend)**：
   - 清爽柱状图对比近几个月支出并标注均值线。
