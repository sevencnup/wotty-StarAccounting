# 消费页账单归类可见性开发文档

## 目标

让账户页中已保存的账单归类在消费页有明确、独立的展示：用户能看到本月账单归类消费总额。

## 已确认原因

消费页分析层会将带 `remarkCategory` 的流水按支出计算，但页面没有独立的归类消费区块；底部明细只展示最新 5 笔，且仅以不显眼的「转账」前缀提示来源。此外消费页固定读取 `default` 账本，可能与归类面板当前账本不一致。

## 实施步骤

- [x] 建立归类流水汇总的回归测试。
- [x] 新增归类消费总额组件。
- [x] 消费页改为读取当前账本并接入归类消费区块。
- [x] 将归类区块精简为仅显示消费总额。
- [x] 运行测试、类型检查与生产构建。
- [x] 完成本地 Git 提交。

## 验收标准

1. 当选月份有已归类流水时，消费页显示「账单归类消费」区块。
2. 区块只显示归类消费总额，不展示笔数、分类或单笔流水。
3. 总额不受底部最近 5 笔明细或当前筛选条件限制。
4. 消费页、归类面板均从当前账本读取数据。
