# API 读取缓存性能优化开发文档

## 目标

- 缩短已访问过的资产、贷款、储蓄、预算等标签页再次打开时的等待。
- 保持 API 为唯一业务数据来源，不将财务数据写入 `localStorage`、IndexedDB 或磁盘。
- 在缓存过期后后台重新请求 API；若数据变化，更新当前页面。

## 实施步骤

1. 在共享云端仓库中为资产、贷款、预算、储蓄目标和储蓄计划增加按账户/目标隔离的短时内存缓存与并发请求合并。
2. 缓存存在时立即返回缓存数据；缓存过期后保留当前显示并后台校验 API 响应。
3. API 返回变化数据时发出内存缓存更新事件，首页/预算、资产、贷款和储蓄页无骨架刷新当前数据。
4. 在保存、删除、导入、切换账号/模式/API 地址时清理相关缓存，避免读到已失效的数据。
5. 更新版本记录，并执行类型检查、测试与生产构建。

## 验收标准

- 首次读取仍由 API 返回真实数据。
- 30 秒内再次进入已访问的资产、贷款、储蓄和预算相关页面可直接使用内存数据。
- 过期缓存不会阻塞页面显示，后台 API 变化会同步到正在打开的页面。
- 数据写入后不会继续返回对应旧缓存。
- 刷新浏览器后内存缓存清空，应用重新从 API 读取数据。
