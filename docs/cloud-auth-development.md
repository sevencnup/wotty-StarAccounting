# 云端登录与账户隔离开发方案

## 目标

- LOCAL 模式继续使用本机 IndexedDB，不要求登录。
- CLOUD 模式必须先注册或登录，API 通过令牌识别当前用户。
- 云端业务接口只允许访问当前用户拥有的账本，不能继续信任客户端传入的用户身份。
- 保留现有数据库数据，登录成功后默认使用已有默认账本；没有账本时自动创建一个。

## 实施步骤

1. 在 API 增加基于 JWT 的注册、登录、当前用户接口，并使用 BCrypt 保存密码哈希。
2. 在 API 增加认证插件和账户归属校验，保护云端数据路由。
3. 在 Web 增加认证令牌存储、登录/注册表单和登出能力。
4. 修改模式切换：切换 CLOUD 前必须完成认证，切换 LOCAL 不需要认证。
5. 认证成功后清理远程缓存，避免不同用户之间复用数据。
6. 更新使用文档并执行 API、Web 类型检查和测试。

## 验收标准

- 未登录请求业务 API 返回 401；健康检查和版本接口仍可访问。
- 注册后可直接获得令牌，登录后可读取自己的账本。
- 其他用户的账本 ID 即使被手动填写也不能读取或修改。
- LOCAL 模式无需网络和数据库即可使用。
- 切换 CLOUD 时弹出登录/注册界面，取消登录不会改变当前模式。
