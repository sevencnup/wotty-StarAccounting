# Web 资产页 UI 全面升级方案

## 1. 目标
按照全站统一的明亮浅色液态玻璃（Light Glassmorphism）与现代化数据可视化规范，将资产页面（`AssetsPage`）全面升级为具有专业金融看板质感、高信息密度与交互美感的资产净值与财务体检中心。

## 2. 升级模块
1. **净资产核心看板 (Net Worth Cockpit)**：
   - 22px 柔和圆角明亮浅色液态玻璃主卡。
   - 净资产大字居中展现，搭配健康状态徽标（结构健康/负债关注）。
   - 资产总额与负债总额的左右分布、双色资产负债对比轨（Asset vs Liability）。
   - 包含财务三大核心指标卡（流动资产、负债率、最大单项）。

2. **资产配置环形构成图 (ECharts Asset Donut & Grid)**：
   - 引入 ECharts 环形图展示现金、银行卡、支付宝、微信、投资、储蓄计划的占比分布。
   - 结合平台专属色调的配置列表（标签、占比百分比、金额）。

3. **三维财务健康体检 (Financial Health Diagnostic)**：
   - 3 项关键维度：流动资产率（现金/支付占比）、负债率（总负债/总资产）、单项集中度。
   - 配备刻度环形图、健康等级标签（稳健/健康/需关注/偏高）及专属建议。

4. **资产与负债资产明细表 (Asset & Liability Ledger)**：
   - 资产账户组：现金、银行卡、支付宝、微信钱包、储蓄计划，配备专属色标徽章、账户名、分类、精确余额。
   - 负债账户组：信用卡、借贷账户、贷款剩余，醒目展示负债金额。
   - 紧凑玻璃卡片排版，解决移动端拥挤与溢出问题。

## 3. 执行步骤
1. 修改 `web/src/app/(tabs)/assets/page.tsx` 引入 ECharts 环形图与现代驾驶舱结构。
2. 修改 `web/src/app/globals.css` 补充资产页面专属液态玻璃样式与移动端适配。
3. 执行 `pnpm --filter wotty-stark-web build` 验证编译与类型安全。
4. 执行本地 git commit。
