# 修复移动端局域网访问开发环境 API 误指向问题

## 更新时间
2026-04-10

## 更新内容
- 修复了手机通过局域网 IP 访问开发环境页面时，登录请求误打到前端 `3000` 并出现 `POST /api/auth/login 404` 的问题。
- 更新 `web/src/lib/api.ts`，当开发环境构建变量仍为 `localhost:3006` 时，客户端会自动把后端地址映射到 `当前访问 IP:3006`。
- 保留正式环境域名访问时优先走同域 `/api` 的策略，不影响服务器部署与反向代理。

## 影响范围
- 前端 API 地址解析：`web/src/lib/api.ts`
- 版本记录文档：`CHANGELOG.md`、`docs/开发进度.md`、`docs/React重构迁移开发文档.md`
