# 2026-04-11 修复静态导出侧边栏路由点击失效并补充导航日志

## 本次目标

解决静态导出部署后，侧边栏中的 `资产 / 消费 / 储蓄 / 贷款 / 连接 / AI` 等页面点击无反应、偶发需要多次点击才跳转的问题，并补充线上可复用的导航捕捉日志。

## 本次完成

1. 统一静态导出导航路径
   更新 `web/src/components/shared/navigation.ts`，把导航项、页面元信息与激活态匹配统一为尾斜杠路径，避免静态目录入口已是 `/assets/`，前端还继续点击 `/assets`。
2. 同步导航预热映射
   更新 `web/src/components/shared/navigation-warmup.ts`，让预热数据与组件映射也改用尾斜杠路径，减少预热与真实命中错位。
3. 加固侧边栏点击跳转
   更新 `web/src/components/shared/Sidebar.tsx`，为主导航点击增加 `pointerdown`、`click-capture`、`touchstart`、`navigate` 日志，并在生产导航时改用 `navigateDocument(href)` 执行文档级跳转。
4. 补充跨页面调试日志
   新增 `web/src/components/shared/navigation-debug.ts`，将最近一次侧边栏导航日志写入 `sessionStorage`，新页面加载后自动回放到控制台。
5. 收口头部相关路径
   更新 `web/src/components/shared/Header.tsx`，统一设置页与退出登录路径为尾斜杠形式，并对搜索跳转使用规范化路径比较。
