# 2026-04-11 修复 Android 联调壳单设备安装识别错误

## 背景

- 联调壳脚本已经能正确打出 APK，但在只有一台 Android 设备连接时，自动安装阶段会把设备号 `b1695dee` 误当成首字母 `b`。
- 结果是脚本报错 `adb.exe: device 'b' not found`，导致自动安装和自动启动中断。

## 本次处理

- 更新 `web/scripts/run-android-dev-shell.ps1`
  - 把 `Get-ConnectedDeviceIds` 改为显式返回数组。
  - 把 `Resolve-TargetDeviceId` 改为强制按数组处理设备列表，避免单设备字符串被 `[...]` 取首字符。
  - 把 `adb install` 与 `adb shell am start` 调整为参数数组调用，减少 PowerShell 参数拆分风险。
  - 安装前增加目标设备日志输出，便于直接确认脚本命中的真实设备号。
- 更新 `web/android/app/build.gradle`
  - Android 版本同步提升到 `2.3.146` / `23146`。

## 用户收益

- 只有一台手机连着电脑时，不再需要手工补 `-DeviceId`。
- 联调壳脚本恢复一键打包、一键覆盖安装、一键启动。
- 真机联调链路更稳定，排查成本更低。
