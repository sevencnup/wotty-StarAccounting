# 2026-04-15 - web-vue 首批公共组件层落地

## 本次目标

在 `web-vue/` 中补齐第一批可复用的 shared/ui 公共组件，避免后续迁移消费页、储蓄页、贷款页时每个页面各写一套。

  - `web-vue/src/components/ui/AppCard.vue`
  - `web-vue/src/components/ui/AppProgress.vue`

## 验证

- `npm --prefix web-vue run build`

## 当前状态

`web-vue/` 已不再只是页面级实现，现已具备：

- 基础 UI 层
- 布局导航共享层
- 空态 / 骨架 / 页面容器
- 页面对公共组件的实际复用链路
