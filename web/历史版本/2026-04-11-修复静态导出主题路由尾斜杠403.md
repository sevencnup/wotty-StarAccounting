# 2026-04-11 修复静态导出主题路由尾斜杠 403

## 本次目标

解决正式环境访问 `/DefaultDashboard/` 这类尾斜杠主题路由时，Nginx 命中同名目录但目录中没有 `index.html`，从而返回 `403 Forbidden` 的问题。

## 本次完成

1. 调整静态导出配置
   更新 `web/next.config.ts`，在 `NEXT_EXPORT=1` 时启用 `trailingSlash: true`。
2. 补齐目录入口文件
   导出后 `web/out/DefaultDashboard/index.html`、`web/out/auth/login/index.html` 等目录首页会一并生成，尾斜杠路径可直接命中页面文件。
3. 兼容 Nginx 静态目录部署
   修复因为路由目录已存在、浏览器又自动补尾斜杠，最终落到空目录返回 403 的部署问题。

## 验证

- `npm.cmd --prefix web run build:export`
- 确认 `web/out/DefaultDashboard/index.html` 已生成

## 结论

这次修复后，部署产物已经兼容 `/DefaultDashboard/` 这种目录式访问方式；只要重新发布到服务器，Nginx 就不会再把该路由当成“无首页文件的目录”返回 403。
