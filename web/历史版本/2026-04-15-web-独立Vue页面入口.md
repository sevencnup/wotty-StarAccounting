# 2026-04-15 - web 独立 Vue 页面入口

## 本次目标

不再让 Vue 以历史 demo 形式挂在旧页面感知里，而是在现有 `web` 站点中提供一个真正独立、可直接访问的 Vue 页面入口。

## 本次交付

- 新增 Next 路由入口：
  - `web/src/app/vue-preview/page.tsx`
  - 访问 `/vue-preview` 时会直接重定向到 `/vue-preview-app/`
- 新增同步脚本：
  - `scripts/sync-vue-preview.mjs`
  - 用于把 `web-vue/dist` 复制到 `web/public/vue-preview-app/`
- 新增根目录命令：
  - `npm run build:vue:page`
  - `npm run sync:vue-preview`
- 已实际生成独立静态页：
  - `web/public/vue-preview-app/index.html`
  - `web/public/vue-preview-app/assets/*`

## 验证

- `npm run build:vue:page`

## 当前效果

现在打开：

- `/vue-preview`

看到的是一套独立 Vue 静态页面，不再是嵌在旧 TS 页面里的 iframe 或 demo 感知。
