# 修复正式环境移动端 API 地址误指向问题

## 更新时间
2026-04-10

## 更新内容
- 修复了正式环境移动端与手机浏览器在构建期仍保留 `localhost:3006` 时，客户端把接口地址误拼成 `当前域名:3006` 的问题。
- 更新 `web/src/lib/api.ts`，让线上浏览器优先走同域 `/api` 反向代理；本地开发环境继续保留 `localhost:3006` / `127.0.0.1:3006` 联调方式。
- API 超时与连接失败提示补充实际目标地址，方便区分是地址解析错误，还是服务器后端未启动、反向代理异常。

## 影响范围
- 前端 API 地址解析与错误提示：`web/src/lib/api.ts`
- 版本记录文档：`CHANGELOG.md`、`docs/开发进度.md`、`docs/React重构迁移开发文档.md`
