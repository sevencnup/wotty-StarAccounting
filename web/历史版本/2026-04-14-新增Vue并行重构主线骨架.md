# 2026-04-14 - 新增 Vue 并行重构主线骨架

## 背景

当前前端正式主线为 `web/`（Next.js + React + TypeScript + Capacitor）。直接切换到 Vue 会带来较高风险，因此采用“并行主线”策略：

- 保留 `web/` 继续承载正式开发与交付
- 新增 `web-vue/` 用于 Vue 3 + Vite 重构，先复刻框架壳与 Android 原生目录，再逐步迁移业务实现

## 本次交付

- 新增 `web-vue/` 工程：
  - `Vue 3 + Vite + TypeScript`
  - `Pinia`（状态管理）
  - `Vue Router`（路由）
  - `lucide-vue-next`（图标）
  - `Capacitor`（Android 壳）
- 复刻框架壳：
  - 登录 / 注册 / 启动页 / 404
  - 工作台布局（侧边栏 + 顶部头部 + 移动底部导航）
  - 主题注册表、主题切换存储、Dashboard 默认入口映射
  - 资产/消费/储蓄/贷款等业务页占位路由
- Android 原生目录：
  - 新增 `web-vue/capacitor.config.ts`
  - 执行 `npx cap add android`，生成 `web-vue/android/`
- 命令入口：
  - 根目录新增 `dev:vue`、`build:vue`、`start:vue` 等脚本，便于并行运行

## 验证

- `npm --prefix web-vue run build`
- `cd web-vue && npx cap add android`

## 后续计划

建议按以下顺序逐步迁移：

1. 登录与鉴权（对接后端 JWT、会话恢复与原生运行时差异）
2. 资产页
3. 消费页
4. 储蓄页
5. 贷款页
6. 数据/连接/设置/关于
7. Android 联调壳脚本与正式 APK 发布链路
