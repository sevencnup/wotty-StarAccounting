# 2026-04-10 修复 Android 状态栏颜色偏黑

## 版本信息

- Android 版本：`2.3.134`
- 文档版本：`docs/React重构迁移开发文档.md -> v1.1.11`

## 问题现象

- APK 页面主体已经是浅色主题，但顶部状态栏仍显示为灰黑色，与页面视觉风格不统一。

## 根因定位

- Android 启动主题和正式主题没有显式统一状态栏颜色。
- 网页层 `theme-color` 在深色模式下会切到暗色值，导致原生系统栏跟着变暗。
- 启动主题未明确声明 `postSplashScreenTheme`，系统栏样式容易继续沿用启动态默认值。

## 本次修复

- 新增 `web/src/components/shared/SystemBarsSync.tsx`，在 Android 原生壳中主动设置浅色系统栏与深色图标。
- 更新 `web/src/app/layout.tsx`，把全局 `themeColor` 统一为浅色值。
- 新增 `web/android/app/src/main/res/values/colors.xml`。
- 更新 `web/android/app/src/main/res/values/styles.xml`，显式设置状态栏 / 导航栏颜色，并补齐 `postSplashScreenTheme`。

## 验证

- `npm.cmd run typecheck`
- `npm.cmd run apk:debug`

## 备注

- 当前会优先保持 APK 与页面浅色视觉一致。
- 如果后续要支持整套深色原生主题，再单独做系统栏跟随主题切换即可。
