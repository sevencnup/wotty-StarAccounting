# 2026-04-10 新增 SSH 远程 MySQL 一键初始化脚本

## 本次目标

为项目补一套适合开源仓库直接交付的数据库初始化方案，让使用者只需要填写 SSH 与 MySQL 配置，就能一键完成远程安装、建库建表和默认管理员初始化。

## 本次完成

1. 新增 `server/scripts/remote-mysql-bootstrap.ts`
   本地读取 JSON 配置后，通过 SSH 连接远程 Linux 服务器，自动生成 SQL、上传文件并执行初始化
2. 新增 `scripts/mysql-remote-init.config.example.json`
   提供可提交仓库的配置模板
3. 更新 `.gitignore`
   忽略 `scripts/mysql-remote-init.config.json`，避免真实密码被提交
4. 更新 `server/package.json`
   新增 `npm run db:remote:init`
5. 新增 `一键初始化MySQL数据库.bat`
   提供 Windows 一键入口
6. 更新 `README.md`
   补充一键初始化说明
7. 新增专项开发文档
   `docs/SSH远程MySQL一键初始化开发文档.md`

## 使用方式

```bash
npm --prefix server run db:remote:init
```

仅校验配置：

```bash
npm --prefix server run db:remote:init -- --dry-run
```

## 验证结果

1. `cd server && npm run db:remote:init -- --dry-run --config ..\\scripts\\mysql-remote-init.config.example.json`
2. 已确认脚本能在当前 Windows 环境下完成配置校验、Prisma SQL 生成和远程初始化脚本渲染
