# 2026-04-11 新增 Android 联调壳一键启动脚本

## 背景

- 直接用手机浏览器访问 `http://电脑IP:3000`，虽然能热更新，但运行环境是浏览器，不是 APK。
- 正式 APK 又最接近真实交付环境，但每次改代码都要重打包安装，联调成本很高。

## 本次处理

- 新增 `web/scripts/run-android-dev-shell.ps1`
  - 自动识别当前电脑的局域网 IP。
  - 默认把前端联调地址写成 `http://局域网IP:3000`。
  - 默认把后端接口地址写成 `http://局域网IP:3006`。
  - 自动执行 `cap sync android`、debug 构建、`adb install -r` 与启动 App。
- 新增 `docs/Android联调壳开发文档.md`
  - 统一记录联调壳命令、参数、用途和日志排查方式。

## 用户收益

- 以后不需要手工改 `server.url=http://...:3000`。
- 不需要再自己拼接 `CAP_SERVER_URL`、`NEXT_PUBLIC_NATIVE_DEFAULT_API_BASE_URL`、`adb install -r` 这些命令。
- 手机里跑的是原生壳 + WebView，更接近正式 APK，又能复用电脑上的前端热更新服务。

## 版本同步

- Android 版本：`2.3.145`
- React + Capacitor 迁移文档：`v1.1.17`

## 验证

- `powershell -ExecutionPolicy Bypass -File .\web\scripts\run-android-dev-shell.ps1 -SkipInstall -SkipLaunch`
