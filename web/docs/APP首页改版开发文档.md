# APP 首页改版开发文档

## 1. 背景

本轮需求是将 `app` 端首页按用户提供的移动端金融设计图重做，并明确要求：

- 顶部系统时间、信号、电池等状态栏不纳入页面真实结构
- 首页整体视觉需要贴近参考图，而不是只保留“蓝色卡片 + 白色模块”的泛化风格
- 底部导航要保留，但样式需更接近设计图中的白色圆角托盘

## 2. 设计目标

本轮首页改版聚焦以下目标：

1. 重做顶部蓝色 Hero 区，强化大圆角、头像位置、蓝色层次和余额卡比例
2. 将四个快捷统计卡压成更接近参考图的小白卡阵列
3. 将 “Spending this month” 模块收敛为左侧圆环、右侧图例的卡片布局
4. 将商户三卡与底部导航一起调整到更贴近设计图的留白与节奏

## 3. 实施范围

涉及文件：

- `app/src/views/HomeView.vue`

## 4. 实现说明

### 4.1 首页主视觉重做

- 删除首页原先绘制在内容里的系统状态栏结构，避免把参考图中的设备系统区误做成业务 UI
- 重新调整蓝色 Hero 容器高度、内边距、头像尺寸和余额卡位置
- 将余额卡从 Hero 内部普通流式布局改为独立叠层，压在顶部蓝色区域上方
- 重做余额卡右侧弧形装饰，让结构更接近设计图中的同心圆弧感

### 4.2 信息卡片比例校准

- 收紧四个统计卡的间距、圆角、字号与 icon 区大小
- 调整消费卡标题区、按钮胶囊、圆环尺寸和图例文字层级
- 调整底部三张商户卡的尺寸、圆角和 logo 呈现方式
- 继续缩窄整体留白与卡片厚度，让首页更接近参考图中的紧凑比例

### 4.3 底部导航重绘

- 将底部导航改为独立白色托盘式圆角壳层
- 收紧图标和文案比例，减弱与页面主体的割裂感
- 保留底部 home indicator，维持设计图中的设备感

## 5. 验证

- 执行 `npm run build --prefix app`
- 构建通过
